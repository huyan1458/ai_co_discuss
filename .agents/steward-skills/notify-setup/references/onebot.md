# QQ 个人号（OneBot）

## 它是什么

- **OneBot 11** 是一套接口标准，规定怎么收 QQ 消息、怎么发消息。
- **NapCat、SnowLuma、LLOneBot** 是实现这套标准的程序：它们挂在 QQ 客户端上，登录一个 QQ 号，在本机开一个 OneBot 接口。
- CoDiscuss 不登录 QQ，只连这个接口（正向 WebSocket）。所以“QQ（个人号）”渠道 = 用户自己运行的 OneBot 程序 + CoDiscuss 去连它。它登录的是普通 QQ 号，可以随时私聊房主，不受官方机器人的主动推送限制。

开始前向用户讲清代价，得到同意再继续：

- **非官方协议**：登录可能失效需要重新扫码，账号有被限制或封禁的风险。
- **要一直运行 QQ 客户端和 OneBot 程序**：实测 Linux 上 QQ 相关进程约占 550 MB 内存。
- **用一个专用 QQ 小号当机器人**。用自己的主号，机器人就是你本人：它没法私聊你，你也分不清哪些话是它发的。
- 一个 QQ 号同时只运行一个 OneBot 程序；一个 OneBot 接口同时只给 CoDiscuss 一家用（见“复用已有的 OneBot”）。

## 方式一：在这台电脑上运行 NapCat

1. 让用户准备好机器人小号，并打开 NapCat 官方文档（napneko.github.io）按其系统选择安装方式（Windows 有一键包，Linux 有 Docker 与 Shell 版）。你可以帮用户下载和解压，但以官方文档的当前步骤为准，不凭记忆编造安装命令；文档与你记得的不一致时照文档做。
2. 启动后按 NapCat 的提示用小号扫码登录（用户在手机上完成）。
3. 在 NapCat 的网络配置里新建一个 **WebSocket 服务器**（正向 WebSocket，不是“反向 WebSocket 客户端”，也不是 HTTP）：
   - 监听地址 `127.0.0.1`（只本机可连，**不要**用 `0.0.0.0`），端口如 `3001`；
   - 设置一个访问令牌（随机长字符串）；
   - 消息格式选 `array` 或 `string` 都可以。
4. 在网页“设置 → 通知”的“QQ（个人号）”一栏填：
   - OneBot 地址：`ws://127.0.0.1:3001`（端口以第 3 步为准）；
   - 访问令牌：第 3 步设置的那串。
   点“保存并验证”。验证会调用 `get_login_info`，成功后提示里会出现机器人小号的 QQ 号。
5. 用户用**自己的主号**私聊机器人小号，只发绑定码。确认 `owner_bound: true` 后“发送测试”。

NapCat 需要保持运行，QQ 掉线时它会提示重新扫码；掉线期间提醒会按顺序改走下一个渠道。

## 方式二：复用已有的 OneBot（如服务器上的 SnowLuma）

适用于用户已经在别的机器上跑着 NapCat / SnowLuma（例如给 Hermes 用的）。

1. **先停掉其他程序对它的连接**：同一个 OneBot 接口如果同时连着 Hermes 和 CoDiscuss，房主发的每一句两边都会收到、都会回复，绑定码也会被当成普通对话。停用别的程序（例如 Hermes 的 QQ 网关服务）属于改动用户的服务，须用户明确同意。
2. **让这台电脑连得到它**。这类服务通常只监听服务器本机 `127.0.0.1`，不要把端口暴露到公网（拿到地址和令牌的人就能以这个 QQ 号发消息）。可选：
   - SSH 隧道（不改服务器）：在这台电脑运行 `ssh -N -L 3001:127.0.0.1:3001 <服务器>`，地址填 `ws://127.0.0.1:3001`。隧道断开时收发也会断，需要常开或设成开机自启。
   - 两端都在 Tailscale 等私有网络里时，把服务的监听地址改到私有网络地址（要改服务器配置，先征得同意）。
3. 令牌用那台服务器上配置的 OneBot 访问令牌：请用户自己查看并填进网页；你若经用户同意去读，只用来填写，不在回答里显示。
4. 其余同方式一的第 4、5 步。

## 常见失败

- “连不上 OneBot 地址”：程序没运行、端口不对、隧道断了，或监听在别的地址。
- 验证时报鉴权失败：令牌不对。CoDiscuss 把令牌放在地址的 `access_token` 参数里（OneBot 11 标准允许）；个别实现若只认请求头，会表现为鉴权失败，请记下所用程序与版本告诉开发者。
- 绑定码发了没反应：确认是私聊机器人小号（不是群里），且 10 分钟内；确认没有别的程序同时连着这个接口。
- 突然收不到：多半是 QQ 登录失效，到 NapCat / SnowLuma 里重新扫码。
