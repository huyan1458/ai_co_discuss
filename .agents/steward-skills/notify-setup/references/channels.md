# 各渠道在平台上的准备

只写在平台上要做的事和常见失败；填凭据、绑定、测试的通用步骤见 SKILL.md。平台界面可能改版，按钮名称对不上时以平台当前界面为准，告诉用户你看到的差异。

## 微信（weixin）

- 网页“设置 → 通知”的“微信”一栏点“扫码绑定”，用个人微信扫码并在手机上确认。
- 绑定后在微信里给机器人发任意一句话，否则还不能发通知（iLink 只能用房主最近一条来信的上下文回发）。
- 常见失败：`-2` 多半是太久没给机器人发消息、上下文失效，发一句即恢复；`-14` 是登录过期，解除绑定后重新扫码。

## Telegram（telegram）

1. 在 Telegram 打开 @BotFather，发 `/newbot`，按提示起名，得到 Bot Token。
2. 这个 Token 只给 CoDiscuss 用：不能同时被别的程序长轮询，也不能设置了 webhook。
3. 绑定时先打开与机器人的私聊点 Start，再发绑定码。
- 常见失败：Token 无效（重新从 BotFather 复制）；`409 Conflict` 表示别处在用同一个 Token 收消息或设了 webhook。

## Discord（discord）

1. 在 Discord Developer Portal 新建应用，进入 Bot 页取得或重置 Bot Token。
2. 同一页开启 **Message Content Intent**（不需要成员和在线状态 intent）。
3. 用 `bot` 权限范围生成安装链接，把机器人装进一个用户自己管理的服务器（不需要管理员权限）。
4. 用户在该服务器的隐私设置里允许服务器成员私聊，然后在 Discord 里打开与机器人的私聊发绑定码。
- 常见失败：`50007` 是当前无法给这个用户发私聊（隐私设置或不在同一服务器）；收不到消息多半是没开 Message Content Intent。

## QQ 官方机器人（qq）

1. 在 QQ 开放平台（q.qq.com）创建机器人，在开发设置里取 AppID 和 AppSecret（不要用旧的 Token 代替 AppSecret）。
2. 确认这个机器人能用正式环境的长连接接收单聊消息；如开了 IP 白名单，加入本机的公网出口 IP。
3. 让用户的 QQ 能打开与机器人的私聊，发绑定码。
- 绑定成功只说明能收消息和被动回复。**能否主动推送要看“发送测试”**，并隔一天在不先发消息的情况下再测一次；被拒时 `last_failure.code` / `detail` 是平台原始错误，常见原因是主动推送权限或额度。
- 想让 QQ 随时主动私聊，又拿不到官方权限的，改用 QQ 个人号（OneBot），见 [onebot.md](onebot.md)。

## 飞书（feishu）

1. 飞书开放平台新建**企业自建应用**（不是群里的“自定义机器人” Webhook），开启“机器人”能力，在“凭证与基础信息”取 App ID 与 App Secret。个人没有组织时可以先免费创建一个。
2. “权限管理”开通 `im:message:send_as_bot`（以应用身份发消息）和 `im:message.p2p_msg:readonly`（读取用户发给机器人的单聊消息）。
3. 发布应用，可用范围里包含用户自己。
4. 先在 CoDiscuss 保存凭据（本机服务会建立长连接），再到“事件与回调 → 事件配置”选择**使用长连接接收**，添加“接收消息” `im.message.receive_v1` 并保存。平台保存时会检查长连接，所以本机服务要开着。
5. 在飞书里搜索机器人、打开私聊发绑定码；发布审批超过 10 分钟导致码过期的，重新保存凭据生成新码。
- 常见失败：权限未开或应用未发布（发送报权限错误）；事件没选长连接或没加 `im.message.receive_v1`（收不到回复）。
