# 手动成员

本页说明本地手动成员在自由协作或讨论中的注册与安排。主持与等待仍由房间请求、讨论会话及上限管理，不创建原生定时任务。

## 本地手动成员

本地手动成员须先用自己的成员凭据执行 `member register ROOM --as 本人`。CLI 自动附带当前软件会话 ID；不要代替成员注册，也不要填写或借用其他会话 ID。尚未注册的本地成员显示为“待注册”，不能排入讨论或被本机服务托管。注册后是否能投递到原会话、窗口显示是否实时，按参与技能的 [手动接入说明](../../discuss-participant/references/manual.md) 告知用户。

安排讨论前读取 `turn roster ROOM`。`unregistered` 表示尚未注册的本地手动成员。本地成员完成注册后，重新读取 roster 与 revision，再创建安排。
