# 给卡片挑平台和模型

> 依据 2026-11 的社区口碑整理，不是实测。模型迭代快，拿不准时问用户，用户的指定优先。

按角色要做的活挑，不按“谁最强”挑：贵模型放在规划、审查等决定质量的位置，便宜模型放在量大、规则明确的执行位置。

| 平台 | 擅长 | 注意 | 适合的角色 |
|---|---|---|---|
| Claude | 写代码执行、前端 UI、长任务先拆再做、叙事与文案 | 额度消耗快，部分地区账号不稳定 | 执行者、写作者、编剧 |
| OpenAI / Codex（GPT） | 推理、审查挑错、复杂排障 | 慢；中文措辞防御性重（“并不代表”），不适合写正文 | 审稿、验收、规划 |
| Antigravity（Gemini） | 中文文笔、知识面广、幻觉低、读长文 | 用词偏西方；最强型号未公开 | 写作者、资料研究 |
| Grok | 单价低、上下文长 | 修复与工具调用口碑差 | 一般不首选 |
| DeepSeek | 快、便宜、规则明确的执行稳定 | 复杂任务吃力；最高思考档效率低，用中高档 | 记录、整理、批量执行 |
| Qwen | 可本地部署 | 思考久、编程口碑一般 | 本地或离线场景 |
| Kimi K3 | 国产上限、前端还原、规划 | 慢、贵、额度少；新版措辞变保守 | 规划、前端 |
| GLM-5.3 | 后端与严肃逻辑可靠；中文小说文笔有人推荐 | 慢、高峰限流 | 执行、审核、写作备选 |
| MiniMax | 价格低 | 能力口碑一般 | 便宜杂活 |

写卡片时：

- 只写本机已配置的平台；不确定时 `model`、`effort` 省略，用本机默认值。
- 纯 API 平台（`OpenAI`、`DeepSeek`、`Qwen`、`Grok`、`Custom`）的成员不读 `effort`，没有命令行，只能用文件工具和 `commands.json` 登记的命令；需要跑脚本的角色，要么登记命令，要么用 `Claude`、`Codex`、`Antigravity` 这类本机软件。
- 同一件事要两个视角审时，两张卡片用不同平台，避免同一家模型的盲点重叠。
