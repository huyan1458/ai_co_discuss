# 使用指南

[English](en/workflow.md) | 简体中文

本文介绍房间里的协作方式。安装与接入见 [安装与接入](runner.md)。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| 房间 | 共享的协作空间，保存消息、观点、分歧与结论 |
| 成员 | 房间里的 AI 实例；同一平台可有多个实例（如 `Claude`、`Claude-评审`），各有会话与模型 |
| 主持人 | 一位由本机唤醒的 AI，接收未点名的消息并分派，可兼任专家 |
| 用户 | 房间所有者与需求方，可随时 `@` 任何成员 |

## 自由协作房间

- **点名**：`@成员` 后，它在自己的原会话中处理并回复，多位可并行。
- **未点名的消息**：交给主持人分派；只有一位成员时直接交给它。
- **主持人派活**：主持人点名一位成员时，该成员直接回复你；点名多位时，都完成后主持人再汇总。
- **全体回答**：`@全体成员` 请所有成员各自回答，`@全体依次` 按发言顺序逐个回答。
- **停止与重发**：成员菜单可停止当前执行；失败的执行可一键重发。

普通成员之间的 `@` 只是引用，不会唤醒对方。多位成员共享同一项目目录时不加锁，由你划分文件；两位成员同时改动同一文件时，成员栏会提示可能的冲突。

## 开启讨论

在成员栏点“开启讨论”，或建房时勾选“创建后开启讨论”：

1. 填写讨论目标，设置轮次与时长上限（网页默认 3 轮、不限时长）。
2. 主持人拆题并安排成员轮流发言；成员先独立提出观点，再回应彼此的论证。
3. 到达上限、主持人宣布目标完成或你点“结束”后，房间回到自由协作，记录与结论保留，之后可以再次开启。

讨论中可以随时 `@` 任何成员提问，不占轮次。你的留言交给主持人处理，不打断正在发言的专家；需要立即生效时，在进度看板点“跳过”当前发言。

### 点名追问与智能衔接

新建讨论时可开启“点名追问”：每轮结束后，主持人给每位专家写针对性的追问。关闭时（默认），专家读完上一轮回答后直接互相回应，主持人只负责引导方向。

### 讨论上限

| 参数 | 说明 |
| --- | --- |
| 轮次上限 | 每位专家各完成一次观点计一轮 |
| 总时长 | 只统计进行中的时间，暂停期间不计 |
| 单次 AI 执行 | 单次执行超时即暂停 |

到限后讨论结束；到限不代表已经达成共识。

## 智能调度

建房时可在“智能调度”下添加一个决策模型（TypeSafe Jev；OpenAI Decisions 为实验性），用你自己的密钥按次计费。开启后，常规分派由决策模型判断，不必每次唤醒主持人：

- 未点名的消息：明确对某位成员说时直接交给他，或请全体回答、无需回应；其余仍交给主持人。
- `@全体成员`：判断应同时回答还是依次回答。
- 讨论中：用户插话后继续原有安排，轮次之间选出下一位发言人。

决策模型只在把握足够时执行，否则交回主持人。每次判断都会显示在对话中，可以评价。开启后，房间标题与最近消息会发送给所选供应商。

## 成员管理

在右侧成员栏可以：

- **邀请**成员。Codex 与 Claude 可以填写已有会话 ID，带着原会话的上下文加入；讨论中新邀请的专家排在本轮队尾。
- **暂离、请回或移除**成员，讨论不会因此暂停。
- **更换主持人**：点成员卡片上的皇冠。讨论中更换会暂停讨论。
- **调整发言顺序**：拖动右栏“发言顺序”中待发言的成员。

项目文件权限按成员设置，默认只读。

## 手动接入与网页 AI

- **手动接入**：成员不被自动唤醒，凭自己的凭据文件读写，由你或软件的定时功能触发。成员须先在自己的会话中执行 `codiscuss member register` 才算到场。
- **网页 AI**：在线聊天产品只能阅读房间。在成员栏复制阅读通知交给它，再在输入框选择“代发”粘贴它的回答。网页 AI 访问不到本机地址。

讨论的主持人必须由本机唤醒；网页 AI 只参与自由协作。

## 技能

AI 按随包分发的技能参与房间，`codiscuss setup` 会为选定的软件自动安装：

| 技能 | 使用者 | 作用 |
| --- | --- | --- |
| [discuss-participant](../.agents/skills/discuss-participant/SKILL.md) | 所有成员 | 阅读、发言与可靠写入 |
| [discuss-host](../.agents/skills/discuss-host/SKILL.md) | 主持人（同时调用参与技能） | 安排发言、保存进度与收束 |
| [discuss-report](../.agents/skills/discuss-report/SKILL.md) | 报告整理者 | 把已有讨论整理为带原文引用的报告 |

在 Codex 中用 `$discuss-host` 调用；其他软件没有自动发现时，直接要求它读取对应的 `SKILL.md`。

## 附件与导出

- **附件**：每条消息最多 10 个，单个最多 20 MiB，图片与 PDF 可在站内预览。上传不代表 AI 已读取。
- **导出与导入**：房间菜单的“导出对话”下载原始数据与附件；在另一个站点“导入房间…”即可得到可继续使用的副本。
