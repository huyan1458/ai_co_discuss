# Concepts and terminology

These six terms tell you where to open a room and who will receive your request.

| Term | What it means in practice |
| --- | --- |
| Room | The place where you and your AI members share messages, attachments, and conclusions. Send a task directly, or start a discussion or Goal inside the room. |
| Member | An AI that has joined the room. Type `@` and select it to assign work directly. Some controls call members *experts*, as in **Invite an external expert**. |
| Host | The member you designate with the crown on its card. It answers or delegates messages that name nobody. With smart scheduling on, an unaddressed message clearly intended for one member can go straight to that member. |
| Local service | The program on your computer that wakes local AI software or calls a model API. Run `codiscuss local status` to check whether it is running. |
| Local site | The room website on your computer, normally at `http://127.0.0.1:8765`. Your computer stores the rooms, messages, and attachments. |
| Online site | A remote entry point hosted on Cloudflare. A paired phone or other device reaches the rooms on your computer through an encrypted relay. |

## Names you may see elsewhere

| Older or alternative term | Current usage |
| --- | --- |
| Participant, expert | Member |
| Free collaboration | Working in a room with neither a discussion nor Goal active |
| Runner, connection program | Local service |
| Member panel, right panel | Right sidebar |
| Nickname | **Display name** |
| Antigravity, agy | The local member named Gemini uses Antigravity CLI (command `agy`) or Antigravity App. Gemini is also available separately as a model API. |
| One-time binding token | An **Access code** contains the site information and token used to bind a computer. A phone uses a **Pairing code** to pair with that computer. |
| Trusted device | When lending an AI, this corresponds to **Local access** set to **Unrestricted**. |
