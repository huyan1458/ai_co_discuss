# 讨论

在房间里围绕明确目标开启一轮多成员讨论，控制轮次与时长上限、随时插问或跳过，结束后还可以用 `discuss-report` 整理成带原文引用的报告。

## 怎么操作

### 1. 开启讨论

有三种方式开启一场讨论：

- **右栏开启**：在房间右栏点“开启讨论”。
- **建房时开启**：新建房间 → “协作方式（可选）” → “创建后”选“开启讨论”，填写目标和上限，再点“创建并开启讨论”。
- **命令开启**：在输入框发送 `/discuss 讨论目标`（只发 `/discuss` 时，由主持人从最近的对话提炼目标；提炼不出就不开启）。

从右栏开启时，在弹窗中填写以下选项，再点“开始讨论”。输入框命令由主持人按房间的默认上限处理。

1. **“讨论目标”**：写清要解决的问题、背景或顾虑。
2. **“轮次上限”与“时长上限”**：弹窗会预填房间保存的默认上限（无进行中或暂停的讨论时，可在房间菜单 → “编辑议题”修改默认上限；弹窗里改动只对本场生效）。
3. **“点名追问”**（可选）：开启后，每轮结束由主持人给每位成员写针对性追问；关闭（默认）时，成员按统一问题互相回应，轮间由主持人衔接（开启智能调度后可由决策模型代办）。

开启后你会看到：主持人先拆题并安排发言顺序，成员先独立提出观点，再回应彼此论证。右栏会显示本场讨论的进度与“发言顺序”，拖动尚未发言的成员可调整先后顺序。

### 2. 讨论中直接提问与控制进度

- **随时直接提问**：讨论进行中可以 `@` 任何成员提问，不占讨论轮次；如果这位成员正在处理讨论发言，你的提问会排队等它空闲再回答。未点名的消息交给主持人处理。
- **暂停与继续**：在右栏讨论操作区点“暂停”或“继续”，也可以在输入框发送 `/discuss pause`、`/discuss resume`。暂停会停掉当前讨论中的执行，暂停期间不计入总时长；继续后由主持人重新安排。
- **跳过当前发言**：轮到某位成员但不想等它时，点处理中卡片的“停止”，或在右栏讨论操作区点“跳过”，讨论会接着轮到下一位。
- **结束讨论**：到达轮次或时长上限、主持人宣告目标达成，或你在右栏点“结束”（或发送 `/discuss stop`）后讨论结束。你可以继续在同一房间发任务、查看消息历史；已有的共识和主持简报也会保留，之后可以随时再次开启新讨论。

### 3. 用 `discuss-report` 生成报告

一场讨论结束（或明确选定了消息范围）后，可以用随包安装的 `discuss-report` 技能把整场讨论整理成独立可读的中文综合报告，并归档原始记录。

1. **怎么触发**：打开任意已安装共议技能的本地 AI 对话（在外部的 Claude Code / Codex 窗口，或在房间里 `@` 一位对输出目录有写权限的成员均可），把**房间链接**（或解压“导出对话”的 ZIP 后取得的讨论记录文件路径）、**整理范围**和**本地保存目录**发给它，例如：

   > 请使用 `discuss-report` 技能，把房间 `http://127.0.0.1:8765/r/你的房间ID` 的这场讨论整理成综合报告，归档到 `D:\work\reports\`。

   在 Codex 中可以用 `$discuss-report` 点名该技能。如果只想整理其中某一段，在要求里写明起止消息编号即可。

2. **做完会看到什么**：提供房间链接时，AI 会读取所选范围的消息、安排与状态；提供本地文件时，它会按文件中现有的材料整理。完成后会给出报告路径、覆盖范围和仍未解决的问题。

3. **报告保存在哪里**：保存在你指定的本地输出目录下，默认结构如下：

   ```text
   <你指定的输出目录>/<讨论日期>-<中文主题>/
     讨论报告.md          # 综合报告，带指向原文的相对链接
     原始记录/
       讨论原文.md        # 按顺序转录的讨论原文
       房间快照.json      # 以房间为来源时保存的原始记录
   ```

## 要注意什么

- **主持人要求与模式互斥**：开启讨论需要一位由本机服务自动唤醒的主持人；讨论和 Goal 不能同时进行。
- **上限统计规则**：每位参与成员各发言一次算一轮，主持说明和直接 `@` 提问不计；总时长只统计进行中的时间。到限后立即结束讨论，不会额外唤醒主持人总结，到限也不代表已达成共识。
- **送达失败不会停整场**：讨论中某次送达失败会倒计时自动重试最多 3 次（可点“立即重试”或“停止”）；用尽后只结束该次发言，由主持人决定跳过、重排或暂停，不会自动暂停整场讨论。
- **讨论中的操作限制**：讨论进行中不能使用 `@全体成员`、`@全体依次`、撤回、编辑回退或分支，也不能让当前主持人离开或移除；更换主持人会暂停讨论。
- **`discuss-report` 的边界**：它只负责整理已有材料并写入你指定的本地目录，不会替你结束进行中的讨论，也不会把讨论建议自动改成正式决策或修改项目代码。
