# 共议（AI CoDiscuss）用户手册

第一次使用请先看[名词与概念](concepts.md)和[第一次使用](first-run.md)，跑通第一个房间后再按“我想做什么”查阅对应页面。

## 目录

| 页面 | 这页讲什么 |
| --- | --- |
| [名词与概念](concepts.md) | 一屏认识房间、成员、主持人、本机服务、本机站点与线上站点，附新旧叫法对照。 |
| [第一次使用](first-run.md) | 使用前须知（费用、系统、数据、关机表现），安装配置、建第一个房间以及从已有对话建房。 |
| [房间目录与建房](rooms.md) | 建房各项设置、左栏目录与文件夹、多个项目目录与“文件”页预览、附件，以及导出、导入和分支。 |
| [在房间里干活](working.md) | 点名、主线与支线、派活标签、排队消息、私聊与执行中插话、停止回退，以及回答成员提问。 |
| [讨论](discussion.md) | 开启多轮结构化讨论、设置上限与跳过暂停，以及用 `discuss-report` 生成带原文引用的报告。 |
| [Goal](goal.md) | 让主持人围绕目标持续推进，设置预算、空闲等待时长与微信待确认提醒。 |
| [工作流](workflows.md) | 安装与补装内置工作流、在房间启用与请离、用 `workflow-creator` 新建修改，以及“主持人完整权限”。 |
| [统计](analytics.md) | 查看全房间每周/每月战报、文件夹精力分布、多房间并行峰值、成员成绩单与卡点，并导出本机分享图。 |
| [平台主理人](steward.md) | 指定本机 AI 和技能处理平台事务，从各处发起请求并在专用对话里查看结果。 |
| [成员](members.md) | 邀请本地软件与模型 API、续接历史会话、更换模型与提示词、项目权限能拦住什么，以及手动接入。 |
| [跨电脑协作（外部成员）](external-members.md) | 借用另一台电脑上的 AI 进房帮忙，设置借出时间、权限边界、续期与撤销。 |
| [手机与外出](remote.md) | 绑定自托管线上站点、在电脑前配对手机或平板、通行密钥（Passkey）续期与远程控制范围。 |
| [智能调度](scheduling.md) | 接入决策模型自动处理常规分派与轮次衔接，配置供应商密钥并评价判断结果。 |
| [语音与通知](voice.md) | 本机与云端朗读和语音输入、用技能安装本机语音，以及绑定个人微信收发通知。 |
| [管理面板与托管账号](admin.md) | 用管理面板或 `codiscuss admin` 启停更新服务、管理登录密钥，以及给他人开隔离托管账号。 |
| [命令行](cli.md) | 按日常场景汇总给人用的 `codiscuss` 命令与帮助查询方式。 |
| [常见问题与设置索引](faq.md) | 新手最常问的 10 个问题、常见故障排查，以及网页“设置”弹窗每一项的说明索引。 |
