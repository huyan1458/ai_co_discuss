# 手机与外出

出门时用手机、平板或其他电脑打开线上站点，经加密中转直接查看房间、发消息、建房并远程控制家里电脑上的 AI。

## 先说清：有没有现成的线上站点？

npm 安装默认提供本机站点，没有随包可直接使用的公共线上入口。外出访问需要一个已部署的线上站点：已有可用站点时，请部署者给你一次性接入码；自己部署时，可使用 Cloudflare 免费方案的 Pages、D1 和中转 Worker。

- 线上站点**不保存房间和消息**，也没有账号密码；它只保存你绑定的电脑和电脑签过名的设备名单，房间数据始终留在你家里电脑上。
- 如果你是通过 `npm install --global ai_co_discuss` 安装的，手里没有源码仓库，自行部署时先运行 `git clone https://github.com/huyan1458/ai_co_discuss.git`，再进入 `ai_co_discuss` 目录。也可以下载源码 ZIP 并解压。npm 安装包没有完整的 Cloudflare 构建源码和部署模板。接下来按[部署指南](../deployment.md#cloudflare-pages--functions--d1)创建资源、初始化数据库并部署。

## 怎么操作

### 1. 把电脑绑定到线上站点

在运行 AI 的电脑上，选下面任一种方式把电脑绑定到已部署的线上站点：

- **命令行绑定**：在终端运行：
  ```sh
  codiscuss local connect https://你的站点
  ```
  如果这台电脑就是部署网站的电脑（已 `wrangler login`），命令会自动生成一次性绑定令牌并完成绑定。如果 AI 跑在另一台电脑上，先在部署网站的电脑运行 `codiscuss token` 拿到令牌，再在 AI 所在电脑执行 `codiscuss local connect https://你的站点 --setup-key <令牌>`。
- **管理面板用“接入码”绑定**：在部署网站的电脑打开管理面板 → “概览” → “本机” → “线上网站”点“生成接入码”（或运行 `codiscuss admin entry code`），复制生成的接入码；再到运行 AI 的电脑打开管理面板 → “概览” → 线上网站点“绑定”，粘贴接入码即可一步完成。

之后不再需要远程访问时，在管理面板点“解绑”，或运行 `codiscuss local disconnect https://你的站点`。

### 2. 在电脑前配对手机或平板

配对时可创建通行密钥（Passkey），以后用面容、指纹或设备锁屏密码确认身份。

每台外出设备第一次使用前，都要在电脑前配对一次，无需注册账号或记密码：

1. 在电脑上打开本机网页，进入“设置 → 账号 → 已配对的设备”，点击“添加设备”。页面会显示一个二维码和 12 位“配对码”（2 分钟有效，只能用一次）。
   - 如果只是临时借用别人的电脑，先勾选“临时设备”（只授权 1 天、不可续期）。
   - 如果旧设备浏览器不支持通行密钥（例如无 Google Play 服务的安卓平板），可勾选“允许不用通行密钥”（不需要每日确认，也不能续期，到期须回电脑前重配，仅在确有必要时勾选）。
2. 用手机或平板相机扫描二维码；不方便扫码时，在手机浏览器打开你的线上站点，打开设置，在“配对这台设备”表单输入 12 位“配对码”。扫码时页面会核对电脑密钥指纹。
3. 按手机提示在使用通行密钥的配对方式下，用面容、指纹或设备锁屏密码确认一次，并在浏览器里创建不可导出的设备密钥与通行密钥。配对完成后，手机左栏“协作房间”会直接列出电脑上的房间。

### 3. 授权期限、每日确认与撤销

- **30 天授权与续期**：普通设备每次授权 30 天。到期前最后 7 天或到期后 30 天内，在手机上打开线上站点设置页用通行密钥确认即可续期 30 天，不用回到电脑前；超过宽限期须回电脑前重新配对。
- **每日确认**：每台支持通行密钥的设备每天首次打开线上站点时，用面容、指纹或设备密码确认一次，之后 24 小时内建房、发消息、调整任意项目权限都不再询问。
- **查看使用记录与解绑**：在电脑或任意其他已配对设备的“设置 → 账号 → 已配对的设备”中，点设备旁的时钟图标（“使用记录”）可查看配对、确认与远程操作记录；设备丢失或发现异常操作，立即点“解绑”。解绑会立即阻止后续远程操作，但已在进行的任务和已改动的文件不会撤回。

### 4. 外出时能做什么

只要家里电脑开机并运行本机服务，已配对的手机和平板几乎与电脑功能对等：

- 查看全部房间与实时更新、发消息、上传附件、语音输入与朗读、导出备份。
- 新建房间、邀请与请回成员、翻开卡片改模型与权限、录入 API 密钥、签发外部成员邀请。
- **目录范围受电脑控制**：外出设备只能选用你在电脑上保存的“常用项目”及其子文件夹（点项目目录栏末尾的文件夹按钮逐层浏览）。需要扩大范围时，在电脑上把上级目录加入“常用项目”。在电脑上给房间或分组配好的其他路径（如“临时路径”），外出设备仍可照常使用或移除，但不能新增这类路径。 在“管理项目…”中，拖动项目左侧的手柄，点“保存”即可更改选择菜单里的顺序。

## 要注意什么

手机端仅支持竖屏布局。平板可横屏或竖屏使用。

- **电脑离线时看不到房间**：电脑关机、休眠或本机服务未运行时，手机目录标题会显示“协作房间（电脑离线）”或“协作房间（电脑未连接）”；电脑恢复在线后页面自动重连。
- **超时不自动重发**：电脑没及时答复时，页面会提示“结果待确认”，不会自动重发；先看房间确认是否已生效。
- **只能在电脑上改的项**：软件可执行路径、常用项目范围之外的目录、以及添加新设备，都只能在电脑前操作。
- **附件缓存**：经中转看过的图片和文件会缓存在这台设备的浏览器里，在这台设备上解除配对时清除。
- **清除浏览器数据需重配**：手机清理浏览器数据会删掉设备密钥，需回到电脑前重新配对；另外转交命令 10 分钟后作废，请保持手机系统时间大致准确。
