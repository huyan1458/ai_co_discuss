# 房间目录与建房

在左栏整理房间与文件夹、按需配置建房选项，并管理项目目录、浏览文件、发送附件以及导出、分享、导入或分支房间。

## 怎么操作

### 1. 新建房间与各项设置

在左栏点“新建房间”（或点某个文件夹右侧的“+”在该文件夹中建房），弹出建房表单，按三节填写：

1. **“这次做什么”**
   - 填写“话题名称”。
   - 按需选择“项目目录（可选）”；不选时，程序会在草稿空间（默认 `~/.codiscuss-workspace`）为这个房间单独建一个文件夹。选好主目录后，可点“添加其他项目目录”再挂最多 8 个目录。
2. **“谁来参与”**
   - 点“添加 AI”加入成员，点卡片上的皇冠指定主持人。
   - 按需配置下方的“智能调度”、“生图”（添加“OpenAI Images”卡片并填地址、API Key 和图片模型；点卡片背面的闪电按钮可检查地址、密钥与模型，不生成图片、不计费）以及“联网搜索”（填 DeepSeek API Key，所有房间共用）。
3. **“协作方式（可选）”**
   - 在“创建后”选择“不开启”、“开启讨论”或“开启 Goal”。
   - 按需设置“自动销毁”（见下文）。
4. **展开“高级设置”**：按需勾选“主持人完整权限”，允许主持人自行管理成员、重试或打断执行、开启讨论与 Goal 及保存工作流，不想全部放开时展开“具体权限”只勾选需要的几项；调整“连续派活上限”（默认 10 轮，可设 1–100 轮或不限）和“API 请求上限”。
5. 按所选方式点“创建并连接”“创建协作房间”“创建并开启讨论”或“创建并开启 Goal”，进入新房间。

话题名称、项目目录和本次成员每次重新填写；智能调度、协作方式、讨论与 Goal 上限、连续派活轮数会自动记住上一次选择（取消建房也保留）。如果启动失败，左栏会留一条失败记录，点菜单里的“重试”可沿用原请求继续，不会重复建房。

也可以在空白首页直接发送消息。网页选第一位已配置且可直接唤醒的 AI 担任唯一成员和主持人，用正文首行命名房间；只发附件时用首个文件名。在设有默认项目目录的文件夹中建房会带入该目录，否则自动建房使用草稿空间。建好后，正文与附件一起发进房间。

### 2. 管理左栏目录、文件夹与存档

- **排序**：点目录右上角选项，在“手动排序”（拖动或用上下方向键调序）和“最近发言”之间切换。
- **文件夹**：点“新建文件夹”按项目归集房间，可为文件夹设置默认项目目录，之后在该文件夹里建房会自动带入。点文件夹菜单可“编辑”、“上移”、“下移”、“存档文件夹”或“移除文件夹”（可选择仅移除文件夹，或连同其中房间一并删除）。
- **房间操作**：点房间右侧菜单，可以“重命名”、“编辑议题”、“移至文件夹”、“复制阅读入口”、“刷新消息”、“存档房间”或“销毁房间”。“编辑议题”和“刷新消息”用于当前打开的房间。
- **销毁房间**：在房间菜单点“销毁房间”。确认框列出会删除和保留的内容，可先点“导出资料包”下载一份：含消息、私聊、附件、可双击打开的“讨论记录.html”，以及成员写在草稿目录里的文件（“草稿”文件夹，超过 50 MB 的部分只列出文件名）。点“立即销毁”，再在“再次确认销毁”里点“确认销毁”后（所有销毁入口都要这样确认两次），这台电脑上的房间记录、附件、成员在本房间新建的 AI 会话记录、运行文件和草稿会被删除：房间立即化成粒子消散（左栏那一行和打开着的中间区域一起），删除与核验在后台继续，全部完成后右下角显示删除了多少。建房时自动创建的草稿文件夹（左侧“项目”里的“草稿”）连同其中文件也会删除，资料包里放在“草稿空间”文件夹；你选的项目文件夹不会删除；沿用你原有窗口的会话、与其他房间共用的会话会保留；已发给模型服务商的内容按其政策保留，无法从这里删除。房间发布过分享网页时，销毁前会先撤销它。某项暂时没删掉时，右下角会提示，可在“销毁记录”里查看并重试。成员草稿目录里的文件会随房间删除，需要的先导出资料包。
- **销毁记录与销毁全部房间**：点左栏房间目录右上角“…”里的“销毁记录”，查看每次销毁删除了什么、保留了什么（房间名在完成后清除），未完成的可点“重试”。底部“销毁全部房间”须输入“销毁全部”确认，会逐个销毁全部房间（含已存档），项目文件保留；以独立 Windows 用户运行的托管账号随后还会删除各 AI 软件里的全部会话记录和 AI 记住的偏好，登录信息保留。“导出全部房间”不含草稿，需要草稿请逐个房间导出。
- **自动销毁**：新建房间时在“协作方式（可选）”里选，或之后在房间顶部的“房间”页，把“自动销毁”设为无活动 1 天、7 天或 30 天后销毁，旁边显示还剩多久；从设定时起算，房间里有新消息或私聊会重新计时；已存档、有成员在工作或排队、有待你回答的提问、发布着分享网页的房间不会自动销毁。剩余不足一天时网页会提示一次，销毁后也会提示。默认“长期保留”。
- **恢复与清理存档**：打开“已存档”，按关键词或有无消息筛选，对选中房间点“恢复”放回活跃列表，单个房间点“彻底删除”并确认；“全部删除”针对当前筛选结果。

### 3. 设置多个项目目录并浏览项目文件

- **增删项目目录**：一个房间可有 1 个主项目目录和最多 8 个其他项目目录。建房后打开顶部“房间”页，在“项目目录”区域可增删其他目录，保存后从各成员下一次执行起生效，不中断会话。主目录设置后不能更改；建房时未设的，可在同一行补设一次。成员按各自项目权限读写全部目录。
- **打开“文件”页**：房间顶部的标签栏点“文件”，浏览目录、文件大小与修改时间，上方可切换主目录与其他项目目录。浏览文件需要已设置项目目录。
- **预览文件**：点击文件打开悬浮预览，支持纯文本、代码、Markdown 渲染、HTML 静态渲染并可切换源码；图片可缩放、旋转；音视频带倍速与全屏直接播放；CSV 显示为表格，字幕（SRT、VTT、ASS、LRC）显示为时间轴；Word、Excel、PowerPoint 与 PDF 只读预览；Premiere 工程显示其 XML；zip 压缩包像文件夹一样列出其中的文件夹与文件，点击其中的文件在新标签中预览。Markdown 中用相对路径引用的项目图片会直接显示。
- **多标签、分屏与收起**：可同时打开多个文件以标签切换，在预览栏切换为右侧分屏、或点“文件位置”回到所在文件夹。HTML 预览还可以“在新标签页打开”。点标题栏“收起”缩成内容区角落的悬浮按钮，切到其他房间后点它即可回到原文件与滚动位置，关闭才清空。
- **摘录批注**：在 Markdown 预览或成员回答正文中选中文字点“添加到对话”，可输入批注并回车，原文标出编号，输入框上方显示“N 条注释”。发送时自动附带文件路径+行号、成员+消息编号，或消息附件所属的消息编号与附件 ID，引用中的 `@` 不会唤醒成员。
- **整理文件**：点路径栏最前面的“项目”，可以打开你所有的项目和草稿。上方按钮用于新建文件夹和上传文件（单个不超过 20 MB）；每行的菜单里有“下载”（文件夹为“下载文件夹”，打包成 ZIP）、“重命名”、“复制”、“剪切”、“删除”，复制或剪切后到目标文件夹点“粘贴”。删除的文件和被替换掉的旧版放进“回收区”，保留 30 天，可以还原。在源码视图点铅笔按钮可以编辑文本文件（不超过 1 MB）。项目、草稿文件夹本身，以及房间正在用作项目目录的文件夹，都不能改名、移动或删除。

### 4. 发送与查看附件

- **添加附件**：在输入框粘贴、拖入文件，或点左下角回形针按钮选择文件（每条消息最多 10 个，单个最多 20 MiB）。添加后输入框上方出现缩略图，正文光标处插入 `[图片 #1]`、`[文件 #2]` 等房间内连续编号的占位标签；删掉缩略图或按退格删掉占位，两边同步移除。
- **查看附件**：消息发出后点正文占位或附件卡片即可打开；图片支持全屏缩放、旋转与保存，音视频直接在消息里播放，文档与代码在文件预览窗口打开。
- **在回答里操作 HTML**：成员正文用 `[文件 #n]` 引用的自包含 `.html` 附件，会在引用位置显示并随房间主题切换。滚到演示时才运行，点下方的“收起”会记住选择。下方也能放大、查看源码或下载。放大的预览窗口、手机全屏预览和“在新标签页打开”也使用房间主题。未引用的 HTML 仍可从附件卡片点“在消息内展开”；超过 2 MiB 或读取失败时改用文件预览窗口。手机上正文引用的演示同样就地显示；未引用的附件点卡片全屏预览。
- **成员读取附件**：本机服务为支持附件的自动执行下载文件，并把文件信息交给接收任务的成员。Claude Code 和 Codex CLI 可直接看图；API 成员需在卡片设置中打开“看图”才能看图，UTF-8 文本附件可按需读取，PDF 等其他文件读不到时会如实说明。

### 5. 导出、导入与分支房间

- **导出备份**：房间菜单 → “导出对话”将当前房间的消息、历次讨论与附件打包为 ZIP；文件夹菜单 → “导出文件夹”；目录选项 → “导出全部房间”。在运行本机服务的电脑上导出，备份会附带成员的软件配置与会话标识。要续接会话，原软件的会话记录仍须保存在电脑上。
- **分享为网页**：房间菜单 → “分享”。程序先读取并整理房间，确认框里列出包含与不包含的内容，以及找到的疑似密钥、本机目录或联系方式（标出消息编号和前后文），核对后选一种方式：
  - “下载网页文件”：得到一个单独的 `.html` 文件，用浏览器直接打开即可，发出去后无法过期或撤回。
  - “发布链接”：上传到官方分享站，得到一个链接并自动复制，选 1、3 或 7 天后过期，到期自动删除。之后左侧房间列表下方出现“已分享”，列出所有有效的分享链接和剩余时间，可以复制、打开、续期（内容不变，有效期从现在重新计算）或撤销；房间菜单里也有“复制分享链接”“撤销分享链接”，再次“分享”可“更新链接”换成最新内容。链接跟着房间保存在电脑上，已配对的手机和平板也能管理；房间文字整理后超过 5 MB 时请改用网页文件。

  两种方式看到的都是这个房间的“消息”和“执行”两页，从头阅读，外观与本机一致，卡片和执行详情都能点开；每次进入“执行”都会从头自动回放协作过程，点“结束回放”回到最终状态。“私聊”“房间”“文件”等标签灰显，只展示示意。但不能发消息或做任何操作；内容停在生成那一刻。私聊、事件记录、调度决策、被拒操作、排队消息、本机路径、会话编号与凭据不会写进去，已撤回或回退的消息也不带；失败原因只写“执行失败”，房间项目目录在正文里改写成项目内的相对路径。消息正文其余部分原样公开，发出前请核对。

  附件默认不带，消息里的附件标记显示为“未包含在分享中”。房间有附件时，确认框里有“包含附件”，勾选后所有附件（图片、视频、网页、文档等）原样放进分享页，读者可以查看和下载；成员回答里交付的项目文件（回答下方的文件卡片）也会作为该条回答的附件一起带上。文本类附件会一并检查疑似密钥和本机目录；图片、视频等文件的内容程序查不了，请自己核对。发布链接带上页面能预览的附件：图片、音视频、PDF、Word/Excel/PowerPoint（docx、xlsx、pptx）、文本与代码、zip 压缩包和网页，读者在分享页里直接打开；js、bat、ps1 等双击就会运行的脚本改名为 .txt 后带上。程序和旧版 doc/xls/ppt 不放到分享站，消息里显示“未包含在分享中”，下载的网页文件仍会带上。网页附件在分享页里照常运行，成员回答里引用的演示直接显示在消息中；它在隔离的框架里运行，读不到分享页，也不能联网请求或提交表单。附件不计入文字的 5 MB，发布链接时逐个上传，合计最多 100 MB，发布按钮会显示上传进度；超过时取消勾选或改用网页文件（同样最多带 100 MB 附件）。
- **导入房间**：目录选项或文件夹菜单 → “导入房间”，选择 ZIP 文件，在预览中确认要导入的房间；标为“已存在，跳过”的房间会保留原样。在同一台电脑导入后，请回成员会续接原会话（Claude Code 成员会改为手动接入，请回后在原窗口重新注册，避免会话分叉）。导入保留历史讨论记录，不会自动继续原讨论或重新唤醒成员。
- **从某条消息分支**：AI 发言菜单 → “从这里分支”，新建一个保留截至该条发言记录的房间。支持会话分叉的接入方式会在新房间续接分叉后的会话；原房间保留。
- **让主持人新建房间**：在“主持人权限”里勾选“新建房间”后，主持人可以把一部分工作拆到新房间：成员只用本机已配置的软件，项目权限默认只读、最高可写，项目目录只能是原房间的目录或其子目录；你没指定时由与原主持人同款的专家主持。两个房间各留一张“关联房间”卡片，点“打开房间”互相跳转。新房间的主持人权限按你的默认设置，但不能再新建房间；一个房间可新建的数量有上限（默认 3 个，可在“主持人权限”里调整）。两个关联房间的主持人可以互相发言，这些消息标注“来自房间「…」的主持人 …”，按你的消息唤醒对方房间；默认不限条数；担心两边来回不停，可在新建房间面板“高级设置”里设“关联房间互传上限”（对本机所有关联房间生效），从你上次在任一房间发言算起超过这个条数会被拒绝，你发一条消息即可让它们继续。

## 要注意什么

- **房间工作结束时提示**：别的房间的工作全部结束（从“正在执行”变为空闲）并保持几秒后，网页右下角提示“房间「房间名」的工作已结束”；正在看的房间不提示，插话、重试这类停下又马上继续的情况也不提示。需要开着网页。
- **共享目录不加锁**：多位成员同时改动同一项目文件时，网页右下角会弹出冲突提示（仅在开着房间时触发，不写进消息记录，也不唤醒主持人）。
- **预览与传输限额**：文本文件最多预览前 128 KB；其他设备经电脑查看媒体与文档时单个文件最多 64 MB，发送 3 MiB 以上视频时网页会先尝试压缩。指向项目目录外的链接会灰显并被拒绝。
- **分支不分叉文件**：分支出的新房间与原房间共用同一项目目录，文件系统不会复制；“从这里分支”需要连接本机服务。
- **上传不等于已读**：把附件发进房间不代表成员已经读过它的内容；执行中插话和私聊不支持发附件。
- **备份版本**：早期第 1 版房间备份不再支持导入。
