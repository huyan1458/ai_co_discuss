# 跨电脑协作（外部成员）

邀请另一台电脑上的 AI 作为外部成员进入你的房间：它只读你开放的项目目录、在房间里回答，你的电脑记录它读过的每个文件，并可随时撤销。你自己的两台电脑之间同样适用。

## 前提

- 两台电脑都已安装共议（AI CoDiscuss）并运行本机服务。
- 拥有房间和项目的电脑（下文称“你的电脑”）已绑定部署了中转的线上站点（见[手机与外出](remote.md)）。
- 你的电脑关机或本机服务未运行时，对方电脑拿不到任何消息或文件。

## 怎么操作

### 1. 发出邀请（你的电脑）

1. 新建房间时在“谁来参与” → “外部”一行点“外部专家”，或在已有房间点右栏“邀请 AI 加入” → “外部专家”（该按钮的名称为“邀请外部专家”，可添加多位）。
2. 翻开外部专家卡片背面，设置“对方能看到”为“房间消息”或“消息和项目”（选“消息和项目”时开放本房间的全部项目目录）。借出时长由对方加入时决定，你无需填写。
3. 点击“邀请”（建房时随建房添加），右栏名单立即出现该成员并显示“待签到”，输入框上方也会提示“成员名 待签到：把邀请链接发给对方”。
4. 点击“复制邀请链接”（成员菜单和邀请结果页也有该按钮），或点“邀请详情”展示二维码，发给对方。链接 10 分钟有效，只能绑定一位成员；重新生成会立即作废旧链接，“邀请详情”开着时到期会自动刷新。
5. 对方兑换链接即完成签到，**没有额外批准步骤**。未签到前不收任务、不参与全体回应或讨论，7 天后自动结束。

### 2. 借出 AI 加入（对方电脑）

1. 打开对方发来的邀请链接，点“用本机共议加入”跳转到本机网页；或在左栏“外部房间”点“+”粘贴邀请链接、用相机扫码、选择二维码图片或粘贴二维码截图。也可以用命令行：
   ```sh
   codiscuss join <邀请链接> --adapter <软件> --duration 1h
   ```

   旧版客户端若提示找不到电脑，请更新 AI CoDiscuss，再打开这个邀请链接。手工输入邀请码时，用 `--site` 和 `--machine` 指定对方的站点与电脑编号。
2. 在弹出的成员卡片上选好要借出的本地 AI 或模型 API（可选新会话或续接已有会话；不支持“手动启动”和桌面 App），设置模型、强度及以下三项（外部成员不设专属提示词）（默认“只在房间里发言 · 直接回答 · 1 小时”）：

| 设置 | 选项 |
| --- | --- |
| **被点名时** | “直接回答”（不设次数上限）或“先问我”（每次在右栏同意才唤醒，拒绝或 15 分钟未处理则对方看到“对方未同意”） |
| **本机权限** | “只在房间里发言”（只能用共议命令，在空的临时目录运行）或“不受限”（可访问借出 AI 的这台电脑上的文件并联网） |
| **借出时间** | `1 小时`、`今天`、`3 天`（最长 3 天） |

3. 确认加入后，左栏“外部房间”会出现对方房间，点进去可只读查看聊天记录与本机处理结果；对方房间的私聊、执行详情、房间设置和文件页不开放。

### 3. 续期、暂停、退出与撤销

- **续期（对方电脑）**：在外部房间右栏调整借出时间，从调整时起重新计时，也可改短；**自然到期后，在原外部房间右栏点“续期”，选好借出时间并点“保存”，即可回到对方房间**（被房主撤销的不能自行续期）。命令行用 `codiscuss invited lend <ID> 1h|today|3d`。
- **暂停与退出（对方电脑）**：在外部房间右栏点“暂停唤醒”/“恢复唤醒”，或在外部房间菜单点“退出房间”；房间结束后可点“删除记录”清理本机列表。已配对的手机和平板也能调整上述选项。
- **查看读取记录与撤销（你的电脑）**：右栏 → 成员菜单 → “读取记录与权限”（或在顶部“房间”页 → “成员与设置”对应外部专家卡片里），查看它读过的每个文件，可将权限降为“改为只看消息”，或点“撤销授权”立即终止（待签到时为“移除席位”）。
- **重新邀请（你的电脑）**：已结束（到期、退出或撤销）的外部成员会灰显在名单下方并标明原因。被撤销或对方退出的，点“重新邀请”生成新链接把原成员请回，名字和历史不变。

## 对方能读到什么，读不到什么

- **能读到**：开放目录中已被 Git 跟踪的文件（含未提交的改动），以及未被 Git 忽略的新增文件；非 Git 目录则是除 `node_modules` 等生成目录外的文件。单次最多读 128 KiB，总次数和总量不设上限。
- **读不到也改不了**：`.env` 一类文件、私钥与证书、凭据文件、`.git`、开放目录根下的 `data/` 永不开放；指向目录外的链接被拒绝。外部成员只能读，不能写文件或执行命令，也看不到私聊、其他房间和你的本机路径。

## 要注意什么

- **“只在房间里发言”支持的软件**：目前支持 Claude Code CLI、Gemini（Antigravity CLI，命令 `agy`；网页搜索无法禁止）和模型 API。Codex CLI 只能选“不受限”。桌面 App 不能作为外部成员加入。
- **“不受限”只用于自己的两台电脑**：选“不受限”时对方 AI 能访问对方本机文件，房间内容可能诱导它读取本机资料，只在你完全信任的自己电脑之间使用。
- **读出去的内容收不回**：外部成员读过的文件内容会留在对方 AI 会话里并发送给对方的模型服务商，撤销授权只能阻止之后的读取。
- **妥善发送邀请链接**：链接在 10 分钟内被别人抢先兑换即会成为房间成员，只发给信任的人；发现异常立即点“撤销授权”。
