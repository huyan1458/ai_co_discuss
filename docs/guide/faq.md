# 常见问题与设置索引

汇总新用户最常问的 10 个问题、典型故障排查，以及网页“设置”弹窗里每一项对应的手册页。

## 新手最常问的 10 个问题

1. **我只有网页版 ChatGPT / Claude / Gemini，或只用 Cursor，能不能用？**
   网页版聊天机器人不能作为成员接入。最低门槛是准备一个模型 API Key（如 OpenAI、DeepSeek、Claude、Gemini 等），或者在电脑上安装并登录一款支持自动唤醒的本地软件（Claude Code、Codex、Gemini）。Cursor CLI 可以借用一张支持“手动启动”的卡，用该席位凭据注册，再到 Cursor 窗口手动查请求、交回答案。[手动接入说明](members.md#手动接入)。详情见[第一次使用](first-run.md#使用前须知)。

2. **使用成本怎么算？**
   共议（AI CoDiscuss）本身免费开源。本地 AI 软件直接走你原有的订阅或账号额度；Cloudflare 线上站点可在免费额度内部署；本机朗读和本机语音输入不计费。模型 API、智能调度、联网搜索、生图和云端语音按你填的 API Key 在对应服务商处计费。

3. **支持哪些操作系统？macOS 和 Linux 能不能完整用？**
   核心功能（本机网站、本机服务、本地 AI 唤醒、模型 API、线上远程访问）支持 Windows、macOS 和 Linux，需 Node.js 24+ 与 Python 3.10+。桌面快捷方式、托盘图标、开机自启与托管账号的独立系统用户隔离和入口保护面向 Windows；macOS 和 Linux 在终端用 `codiscuss` 命令管理。

4. **第一次打开房间，第一步具体该做什么？**
   打开 `http://127.0.0.1:8765` → 左栏“新建房间” → 填话题名称 → 点“添加 AI”加入一位已配置的成员并确认它带皇冠 → 点“创建并连接” → 在输入框打 `@` 选中它发一句测试消息，看到它回复就算跑通。完整步骤见[第一次使用](first-run.md#3-在网页建房收到第一条回答)。

5. **普通房间、讨论、Goal 和工作流怎么选，能不能叠加？**
   - **普通房间**：随时 `@` 成员或发给主持人分派，做完就停下等你。
   - **讨论**（`/discuss`）：设目标和上限，让多位成员先独立表态再互相交锋。
   - **Goal**（`/goal`）：设一个大目标，房间空闲时自动续跑主持人，直到完成、卡住或到预算。
   - **工作流**：保存好的多人分工与角色卡片，一键复用到新房间。
   **能否叠加**：讨论和 Goal **不能同时进行**；工作流可以和普通房间、讨论或 Goal 搭配使用。

6. **把本地项目目录挂进房间安不安全？“只读”能拦住什么？**
   成员默认“只读”。模型 API 成员的只读由本机服务拦截写入和非共议命令。Codex CLI 的写入限制取决于沙箱是否可用，Claude Code 已有授权和 `agy` 历史会话的原项目权限也会影响实际范围；Codex App、Antigravity App 与手动接入成员无法由程序强行拦截，实际权限以原软件为准。撤回或回退对话**不会**撤销成员已经改动的项目文件。对照表见[成员 → 项目权限能拦住什么](members.md#项目权限能拦住什么)。

7. **多个 AI 在一个房间里发言，Token 和额度消耗大不大？怎么控成本？**
   共议不会在每次唤醒时把全部历史打包塞给 AI，只发本次要回应的问题和入口，由成员按需增量读取。控成本可以用三招：建房或“协作设置”里调小“连续派活上限”和“API 请求上限”、给讨论设轮次和时长上限、给 Goal 在“高级设置”里设续跑上限和时长上限。

8. **AI 在房间里干活时，我还能在原软件窗口里正常用它吗？**
   可以。程序新建的房间会话独立运行，不会干扰你平时在 IDE 或终端里开的新对话。如果你用“历史会话”续接了一个旧对话，CLI 软件会把它复制成新会话运行，原窗口不受影响（原软件里也看不到房间记录）；Codex App 则直接复用该原聊天，不要同时在两边往同一个聊天里发指令。

9. **所有数据存在电脑哪里？换电脑怎么迁移？**
   默认保存在 `~/.codiscuss`（本机网站数据库在 `~/.codiscuss/local/discuss.sqlite3`，还有本机配置、密钥、预设与工作流）；不选项目目录时房间文件在 `~/.codiscuss-workspace`。迁移单个或多个房间可用网页“导出对话” / “导出全部房间”导出 ZIP，在新电脑用“导入房间”恢复；工作流可直接复制 `~/.codiscuss/workflows/` 里的对应文件夹。

10. **电脑关机、休眠或断网后，进行中的任务、Goal 和手机端会怎样？**
    关机或休眠会中断本机执行。仅断网时，本机服务可能仍在运行，但手机无法经线上站点访问，依赖模型网络连接的任务也会受影响。重新开机并启动服务后，授权期内的手机会自动重连，无需重新配对；已中断的任务不会自动重跑，先查看房间里的回答或失败卡再决定是否重试。

## 常见故障排查

- **成员没反应 / 一直显示等待**：先运行 `codiscuss local status` 看本机服务是否在线；若房间有正在进行的任务，新消息可能在输入框上方的排队区等待空闲；若怀疑状态卡住，运行 `codiscuss room events <房间ID>` 查事件记录。
- **送达失败 / 投递失败卡**：查看失败卡上的原始原因。若是登录失效，在本机对应软件（或管理面板“账号 → 命令行登录”）重新登录后点“立即重试”；倒计时最多自动重试 3 次。
- **Gemini 做到一半断网**：Antigravity CLI 确认可重试时，共议在同一张执行卡上倒计时，依次等待 10、30、60 秒，在原会话接着做。每次执行最多自动重试 3 次。倒计时期间可点“立即重试”或“停止”；次数用尽仍失败，卡片保留最后一次报错。
- **额度用尽 / 输出超限 / 压缩失败 / 策略拒绝**：
  - 额度用尽：等重置，或在顶部“房间”页 → “成员与设置”给该成员换模型、改派其他成员。
  - 输出或上下文问题：输出达到上限时要求更短的回答或拆分任务；压缩失败时缩短输入，下次执行会自动新开会话。
  - 安全策略拒绝：核对内容与服务商要求，不要原样重试。压缩失败和策略拒绝不会自动重试。
- **Codex 提示会话被占用**：原聊天正在被 Codex App 占用，可在右栏或顶部“房间”页 → “成员与设置”切换到 Codex App 接入，或新开会话。
- **重启本机服务后上次执行状态不明**：服务重启时若原进程已退出，会先核对记录，确认正常完成且符合收录条件会自动补收，否则报“重启后无法确认上次执行结果”，请核对原会话后再决定是否重试，不要盲目重发。
- **Windows 报告两处数据路径**：在普通终端管理服务，或显式设置环境变量 `DISCUSS_SERVICE_HOME` 指向同一目录。

## 设置项索引

想知道这一版改了什么：点网页左上角“AI CoDiscuss”后面的版本号，打开“更新日志”，默认显示当前版本，点“查看更早的版本”看以前的。

下面列出网页“设置”弹窗中的分组与每一项，方便按功能找到说明页：

| 设置分组 | 界面项名 | 说明所在页 |
| --- | --- | --- |
| **账号** | 设置管理员账号 / 登录 / 退出登录 | [部署指南 → Python 服务](../deployment.md#python-服务) |
| **账号** | “显示名称” / “更换头像” / “网站登录” / “更改密码” | 自托管 Python 站点的管理员账号管理（本机 `127.0.0.1` 自动为管理员，无需登录） |
| **账号 → 已配对的设备** | “添加设备” / “临时设备” / “允许不用通行密钥” / “配对这台设备” / “使用记录” / “解绑” | [手机与外出](remote.md#2-在电脑前配对手机或平板) |
| **外观** | “协作频道” / “协作频道 · 浅色” | 网页界面外观，点击即生效 |
| **外观 → 语言 · Language** | 界面显示语言（简体中文 / English） | 网页界面语言，切换即生效 |
| **外观 → 视觉效果** | “完整” / “精简”（关闭毛玻璃模糊与多层阴影） | 低配设备或追求流畅滚动时切到精简模式 |
| **阅读 → 对话宽度** | “窄” / “默认” / “宽” | 网页阅读排版，点击即生效 |
| **阅读 → 卡片文字大小** | “小” / “中” / “大” | 消息卡片里正文的字号；默认“中”，只对当前设备生效 |
| **阅读 → 回答收起长度** | “0.5 屏” / “0.7 屏” / “1.2 屏” | 回答超过所选屏数时收起；默认“1.2 屏”，只对当前设备生效 |
| **阅读 → 折叠后显示** | “少” / “中” / “多” | 收起后保留开头约 0.35 / 0.6 / 0.9 屏，按屏幕高度换算成行数，手机、平板、电脑各不相同；默认“中”，只对当前设备生效 |
| **房间偏好 → 主持人默认权限** | “只读” / “可写” / “自动” / “全放开” | 新建房间时第一位加入的成员（默认主持人）的项目权限，默认“只读”；该软件不支持所选档位时仍为只读。保存在本机服务里，升级不丢，需连接本机服务 |
| **语音** | 朗读服务 / 音色（通用、各平台、文件）/ 语速 / 语气 / 语音输入服务 / “本机进程” | [语音与通知](voice.md#朗读与语音输入本机与云端的区别) |
| **通知** | 微信：“扫码绑定” / “发送测试” / “解除绑定” | [语音与通知](voice.md#微信通知) |

工作状态提示、专家卡片翻面和文件预览窗口的收起、展开与布局切换由站点统一控制。系统的“减少动态效果”设置不会改变这些动效。托管登录页始终播放品牌动画。
