# 智能调度

接入轻量决策模型，自动处理房间里的常规分派与轮次衔接，不必每条消息都唤醒 AI 主持人，判断耗时可在决策卡上查看。

## 能做什么，不能做什么

- **能做什么**：
  - **未点名消息分派**：明确对某位成员说时直接交给它，或判断为请全体同时回答、按发言顺序依次回答、无需回应；把握不足时仍交回主持人。
  - **讨论中衔接**：把局部追问转为不计轮次的普通提问（保留原讨论队列），并在轮次之间选出下一位发言人。
  - **Goal 空闲判断**：Goal 进行中、房间空闲时，判断最近的回答是否已在等你回复，有把握时暂不唤醒主持人。
  - **循环接力返工判断**：循环接力每走完一圈，判断最后一位（如评审）是否明确要求返工；有把握时自动开下一圈，认可或需取舍时交主持人验收。
  - **只读评审交接**：主持人派活时可以指定谁来检查交付、检查哪些内容。若智能调度确认整批交付齐全，就交给这位成员做只读检查，再把评审结果交回主持人；用户无需在界面上另行批准。
- **不能做什么**：
  - 不生成长文本回答，不评价代码或方案对错，不自己改成员顺序、不另选评审者。
  - `@全体成员` 始终同时回答，`@全体依次` 始终按顺序回答，不经智能调度判断。
  - 置信度不够、输入超限或调用出错时，自动交回主持人处理。

## 怎么操作

### 1. 打开并配置智能调度

1. **建房时开启**：新建房间 → “谁来参与” → “智能调度”一节，点要使用的供应商（只能放一个，点另一个会替换）。
2. **已有房间开启**：左栏“房间”页 → “成员与设置” → “协作设置” → “智能调度”，勾选“开启”；若配置没有展开，点“设置”。
3. **填写模型与密钥**：点决策模型卡片的“设置”区域翻面，确认“模型”，填入对应供应商的“密钥”（密钥只保存在本机，填完光标移出或按 `Enter` 自动保存）。
4. **测试配置**：点卡片右上角闪电图标（“检查智能调度配置”），发送一道极短是非题验证；右下角提示“检查通过：决策模型已响应”即配置成功。点“完成”返回。
5. **选择“判断方式”**：卡片下方可选“引导（试验）”（默认，正在打磨，可能判错）或“稳定”（按固定顺序核对，已通过回归评测）。

给成员写好分工描述（右栏 → 成员菜单 → “名称与描述”）能明显提高分派准确率。

### 2. 查看判断结果与给出反馈

- **在房间里看到什么**：每次调度都会在对话流中留下一张决策卡，显示决策模型选了谁或为什么交回主持人。当模式为推荐时，卡片上还会出现“采纳”按钮，主持人空闲时点一下即可派发；主持人正忙时，先选怎样处理当前工作。“取消采纳”关闭这次选择，不能撤销已派出的请求。
- **查看完整输入**：点决策卡上的“模型输入”，可展开核对决策模型当时看到的题干、上下文、候选项；判断结果的置信度显示在卡片标题旁。
- **点赞或点踩反馈**：房主可以点决策卡上的 👍（“判断得好”）或 👎（“判断得不好”）保存评价（点踩时可补充应答成员与备注），用于对比不同判断方式的表现。

## 要注意什么

- **需要连接本机服务**：智能调度由本机服务调用，未连接本机服务时无法开启。
- **数据发送范围**：开启后，房间标题和最近 10～20 条消息会发送给所选决策模型供应商；主持人已安排只读评审时，还会发送该批完整委派、交付原文和执行报告；循环接力判断会发送主持人安排和本圈各成员的完整回答。
- **按房间独立开关**：智能调度按房间生效，随时可以在“协作设置”关闭，关闭后未点名消息按房间原有规则处理。
