# 管理面板与托管账号

通过本机管理面板（或对应 `codiscuss admin` 命令）启停和更新共议（AI CoDiscuss）服务、管理各 AI 软件登录与密钥，还可以给家人或同事开设托管账号共用这台电脑上的 AI。

## 管理面板怎么打开，各页有什么用

- **怎么打开（Windows）**：在终端运行 `codiscuss setup` 时勾选“创建‘共议’快捷方式”（或之后运行 `codiscuss launcher`），双击桌面“共议”快捷方式启动后，任务栏右下角会出现共议图标（首次使用请在 Windows“设置 → 个性化 → 任务栏 → 其他系统托盘图标”里打开“共议”使其常驻）。左键点击托盘图标打开管理面板（或在终端运行 `codiscuss panel`），右键可打开网站、重启或关闭服务。面板只允许在本机打开。
- **“概览”页**：
  - **本机**：查看“共议服务”运行状态，点启动、重启、停止或“打开网站”；开启托管管理后还显示供隔离账号使用的“程序副本”。
  - **本机 / 自建中转**：查看本地网页和已绑定的线上网站地址，可“绑定”、“解绑”或“生成接入码”。
    “自建中转”和 `codiscuss admin status` 均在收到本次连接的心跳回应后显示“中转已连接”，遇到断线、重连或连续 HTTP 请求失败会说明原因，服务停止或记录过期时显示“状态未知”。中转连续 3 分钟未获心跳确认时，服务会重建该网站的连接。也可以点“立即重连”或运行 `codiscuss admin site reconnect`。

    使用自己的反代域名时，在同一行点“其他访问地址”添加 HTTPS 地址，再从新地址配对。见[用自己的域名反代](remote.md#用自己的域名反代)。

    在“概览 → 本机 → 自建中转”一行右侧，用地区下拉框（“中转地区”）选择中转位置，默认亚太。该设置适用于管理员远程访问、经自建中转登录的托管账号和外部专家邀请。选“自动”时，Cloudflare 在最先发起连接的一方附近创建对象，通常靠近电脑的网络出口，建好后位置固定；其他选项是位置提示。服务同步设置后，电脑和已配对设备自动重连。命令行用 `codiscuss admin site region` 查看，用 `codiscuss admin site region weur` 切换到欧洲西部。
  - **托管账号入口**（开启托管管理后显示）：启停“登录入口”，开关“自建中转”或配置“Cloudflare 隧道”。
  - **设置**：查看当前版本、“检查更新”与“更新并重启”（同步更新房间技能和隔离账号）、开关“登录 Windows 时自动启动”，以及切换管理面板语言。
- **“存储”页**：
  - 查看本机 `.codiscuss` 数据总量（上限 10 GiB，不含语音模型）、全机草稿区占用（上限 3 GiB，单房间 1 GiB）、**房间记录与附件（`local/`）**占用、所在磁盘剩余空间与安全线，以及按房间与成员拆分的草稿占用和权限不可读条目计数；本机朗读与语音识别模型单独列出，不计入 10 GiB 上限（兼容旧目录与自定义模型目录，服务根目录为目录联接时也可正常计量）。
  - 当 `.codiscuss` 数据达到 8 GiB 预警线时，“存储”标签显示提示圆点并弹出警告；超过上限或磁盘低于安全线时停止新的派活。总量分为五个具名目录和“其他”。“安全清理”回收已登记的失败执行临时目录、朗读缓存、无主空目录和仅剩登记文件的过期启动目录，以及本机站点已结束超过 24 小时的执行文件。清除朗读缓存后，用云端语音重听旧内容会重新合成并计费。“深度修理”先预估容量，勾选并确认后可删除含最近一天在内的已结束执行日志。
  - “房间附件”按占用从大到小列出各房间已发出、尚未清理的附件；点“管理附件”展开，与房间页的附件管理相同（见[管理房间](rooms.md)“存储空间与上限”）。
  - 点“让平台主理人分析占用”，或运行 `codiscuss admin storage analyze`，可盘点本账号的成员草稿、运行日志、工作流备份、房间附件和本机语音模型。结果在[平台主理人](steward.md)对话查看。默认不删除，清理前须逐项确认，不扫描整个磁盘。
  - **超限脱困与边界**：若全机限制已拦住主理人，先从管理面板查看占用并释放空间。房间记录不会自动删除；附件可单独清理，销毁旧房间前请先导出备份。沙箱创建的不可读目录不计入配额，页面会标出数量；所有限额均为定期采样检查（有执行时每 2 秒查磁盘余量、每 30 秒扫描占用），并非文件系统写入层硬拦截，不能保证磁盘绝不写满。
  服务执行期间，每 2 秒检查服务目录所在卷的可用空间。10 GiB 预算还有余量时，卷上可用空间的下降量达到该余量就提前复扫。执行结束时更新相应成员的草稿占用。清理后手动重试会按原拦截原因复核；全机超限时重新统计全机用量。其他程序写盘时，若可测用量未超限且不可读项数量稳定，运行继续。提前复扫发现不可读项增多时暂停派活，并请求停止可停执行。后续扫描确认数量稳定且各项限额与磁盘余量正常时，恢复派活。低于磁盘安全线仍独立触发保护。房间草稿达到 80% 时，守卫提前暂停无法确认可停止的新执行。采样之间及扫描期间仍可写入，已运行的不可停成员可继续写入。项目目录、系统临时目录与第三方 AI 自身数据在服务目录外时不计入预算。按失败卡上的原因清理后，在卡片上点“重试”。本机和已配对设备都可手动重试。
- **“账号”页**：
  - 左侧默认有“管理员（本机账号）”，开启托管管理后下方列出所有“托管账号”和“新建账号”按钮。
  - 选中“管理员”或某个托管账号，可统一管理它的**命令行登录**（Claude Code / Codex / Gemini 登录状态、切换登录方式或退出，Claude Code 推荐 Setup Token）、**API 密钥**、**技能**（从“技能库”勾选安装或拖入 `.zip`/文件夹导入）、**随包工作流**与**系统提示词**（托管账号可编辑：发给该账号由共议唤醒的所有成员，排在该账号用户自己在“设置 → 系统提示词”里写的内容之前，用户在网页和命令里改不到（它保存在该账号自己的服务目录，不是防篡改保证）；不写入 CLAUDE.md、AGENTS.md；管理员本人的在网页“设置”里改）。程序更新不会改动已装的工作流；工作流区的用法同概览页的检查更新：标题旁标出“已是最新”或可同步的数量；右上角按钮在一致时是“检查随包工作流”，有差异时变为蓝色的“同步到最新版”，确认后补装缺少的、用最新版替换不同的（被替换的旧版先备份到该账号服务目录的 `backups/workflows`，在这里做过的修改也会被替换）。

## 托管账号：给别人开账号用这台电脑上的 AI

新建账号时可填“项目数据目录（可选）”，或运行 `codiscuss admin account add alice --project-data-root "D:\CoDiscussData\alice"`。父目录须已存在，账号专用目录由程序创建。项目、无项目房间的工作区及成员草稿分别放在其 `projects`、`workspace`、`drafts` 下。服务配置、凭据、房间数据库和附件仍存于账号的服务目录。留空沿用默认布局。

在“存储”页设置“单个附件上限（MiB）”。默认 50，可填 1 到 90 的整数。命令行运行 `codiscuss admin storage attachment-limit 75`，省略数值可查看当前设置。自托管 Python 站点可在数据库同目录的 `attachment-limit.json` 写入整数（例如 `75`），也可用 `DISCUSS_ATTACHMENT_POLICY_FILE` 指定文件路径。

**云空间（对象存储）**：每个账号一份云空间，建在资源中心的对象存储上，由程序管理。大于“走云空间的门槛”的附件（单个最大 2 GiB）存到这里，其余仍作普通附件保存在电脑上。你或托管客户发的大文件、成员交付的大文件都存在这里，在外也能从房间里取走。文件只经房间附件进出：不能脱离房间上传，也不建文件夹。

在“存储”页的“云空间（对象存储）”里设置：

- **资源中心地址与 Key**：先填“资源中心地址”，再填“对象存储 Key”，离开输入框或按回车即保存。每个账号各用自己的 Key，和 API 密钥一样存在该账号的密钥库里。已保存的 Key 不会回显；换了地址要重新填 Key。
- **保留天数**：默认 0，表示不开启按天删除。填 1 到 30 时，从文件上传完成起算，到期清理，卡片随后显示“已从云空间删除”。未发送、也未排队的附件满 24 小时后由定期清理移除，即使已传完。
- **空间上限（MiB）**：默认 10240（10 GiB）。用满后新的大文件上传会被拒绝，提示已用和上限，需要先删除旧文件。管理员可为每个托管账号单独设置，托管账号自己不能改。
- **走云空间的门槛（MiB）**：默认 20，最大为单个附件上限。门槛低于附件上限时，介于两者之间的文件（默认 20 到 50 MB）也会改存云空间：消息里没有预览或播放，唤醒成员时也不会自动下载，视频不再在浏览器里压缩、保留原画质。不想要这个变化，把门槛设成和附件上限一样即可。
- **管理云空间**：列出本账号所有房间里的大文件（名称、大小、所在房间、时间），顶部显示已用和上限，可勾选删除。删除后消息仍在，卡片显示“已从云空间删除”。
- 点“测试连接”确认可用。点“清除”只解除配置，Key 仍留在密钥库，可在“账号”页的 API 密钥里删除。

开启托管时，可在上方切换账号，替托管账号填写和管理；托管账号也可在房间网页的“设置 → 账号 → 云空间（对象存储）”自行填写 Key、调整保留天数和门槛、管理云空间。管理员代填时，对方界面显示“管理员提供”。对方界面不显示 Key，但对方账号里的 AI 成员能读到本账号的密钥文件；请给每个账号单独的 Key。

命令行：

- `codiscuss admin storage object` 查看状态。
- `--url 地址 --key-file 文件` 保存。Key 从文件或标准输入读取，不写在命令行里。
- `--test` 测试连接，`--clear` 清除。
- `--retention-days 天数`（0 到 30，0 为不自动删除）、`--quota-mib 大小`、`--threshold-mib 大小` 分别设置保留天数、空间上限和门槛。
- 加 `--account 账号名` 操作托管账号，省略时操作管理员。
- 列出与删除云空间里的文件：`codiscuss admin storage object list`、`codiscuss admin storage object delete`，同样可加 `--account 账号名`。

注意：

- 网页直接把文件上传到存储桶，存储桶须在跨域（CORS）设置里放行打开网页的地址（本机地址、线上站点地址），否则上传会提示无法连接对象存储。
- 每个账号的 AI 只能读到本账号的 Key。给多个账号填同一个资源中心 Key 时，这些账号的 AI 读到的仍是同一个能看到整个目录的 Key；要彻底隔离，需要资源中心为每个账号分别发 Key。
- 清除配置后，大于门槛的文件不能再上传，已存在云空间的附件也无法下载。
- 自动删除和手动删除都由这台电脑上的网站执行。不要对这个目录设置自动删除规则，否则会删掉需要长期保留的文件；电脑卸载或账号删除后留下的文件，由管理员在资源中心手动清理。
- 自托管 Python 站点：在数据库同目录放两个文件，地址须一致：
  - `api-keys/<UUID>.json`，内容为 `{"base_url": "资源中心地址", "api_key": "Key"}`；
  - `object-storage-settings.json`，内容为 `{"base_url": "资源中心地址", "api_key_ref": "<UUID>"}`，可另加 `retention_days`、`quota_mib`、`object_threshold_mib`，省略时按 0、10240、20。

存储统计合并服务数据与成员草稿，项目文件和工作区不计入草稿配额。分卷时，两卷都须满足各自的可用空间安全线。管理面板和主理人盘点使用该账号当前的草稿位置。跨盘项目存储与“限制其他盘”互斥，独立 Windows 账号必须能访问项目数据卷。

Windows 可以从托盘打开面板。macOS 和 Linux 的命令行入口见下文。

一般自用不需要打开托管管理。想让家人、同事通过外网浏览器登录并使用你电脑上的 AI 时，再开启它：

### 怎么操作

1. **开启托管管理**：运行 `codiscuss setup --hosting`（或在 `codiscuss setup` 的“安装配置”里勾选“托管管理”；关闭用 `--no-hosting`，选择会记住）。
2. **新建账号并隔离**：在管理面板 → “账号” → 点“新建账号”，填写账号名，在 Windows 上默认勾选**隔离**（为该账号创建一个独立的 Windows 用户，电脑会弹出一次管理员确认）。向导会一次装好它的程序副本、房间技能、系统提示词和随包工作流并启动它的网站实例，最后**仅显示一次密码**，记得保存发给对方。
   - **为什么要隔离**：未隔离的托管账号会以你的 Windows 身份运行，其 AI 能读到你的个人文件，且与管理员共用登录和技能；隔离后使用独立的 Windows 用户、登录与目录。
   - **入口保护**：在托管账号详情页默认开启“入口保护”（仅支持 Windows），开启后只有经登录入口验证的使用者和它自己的 AI 能访问该实例网站，防止本机其他程序直接访问。
3. **配置外网入口（二选一或同时开启）**：
   - **自建中转（无需自己的域名）**：先按[部署指南](../deployment.md#托管账号的入口可选)部署好入口 Worker；在部署电脑的“概览 → 本机 → 自建中转”生成接入码后，在这台电脑的管理面板“概览 → 本机 → 自建中转”绑定并打开“托管账号入口”里的“自建中转”（命令行一步完成：`codiscuss admin entry join <接入码>`）。
   - **Cloudflare 隧道**：在“托管账号入口 → Cloudflare 隧道”点配置，按提示授权 Cloudflare 隧道并绑定托管在 Cloudflare 上的域名（命令行 `codiscuss admin entry tunnel <域名>`）。更改代理或网络设置后，点“重新连接”或运行 `codiscuss admin entry tunnel reconnect` 让隧道使用新路由。切换时访问可能短暂中断，已登录的客户保留会话。
4. **管理账号**：在托管账号页面可以启动/停止实例、停用/启用账号、重设密码、删除账号、配置由管理员提供的 API 密钥（对方界面只显示“管理员提供”，无法查看或更换），并复制登录地址与账号发给对方。邀请外部专家需要该实例具备可用的线上中转入口。面板每分钟检查已要求运行的实例，端口拒绝连接时自动重启，10 分钟内最多 3 次。达到上限仍失败时，账号行显示最后原因，`codiscuss admin status` 可查最近一次尝试。修好原因后手动启动可恢复巡检。

### 把已有账号的项目数据迁到另一块盘

先结束该账号正在执行的任务，并关闭仍在写项目文件的外部程序。在账号详情填入一个尚不存在的绝对路径（父目录须已存在），点“停止实例并迁移”。命令行可运行 `codiscuss admin account migrate-data <账号> --project-data-root <新目录>`。请选管理员控制的父目录，确保目标卷有空间容纳完整副本；隔离账号还需要能访问该卷。

迁移覆盖项目、房间工作区和成员草稿。程序停止实例，逐文件校验 SHA-256，旧路径通过目录联接指向新位置。完成后手动启动实例。复制出错并回滚时请改用新的空闲路径；面板中途退出时请以相同目标重试。目录树中的链接和特殊文件会中止复制。跨盘存储与“限制其他盘”互斥，开启磁盘限制时须选择允许访问的卷。

旧备份保存在原卷的运行配额目录之外，仍占用原卷空间。在账号详情点“查看迁移备份”，可按目录查看管理员登记的位置和当前文件字节数和磁盘占用。点“释放迁移备份”并确认会停止实例，核对备份、目标和联接后只删除选中的备份。迁移后可正常增删改项目和草稿文件。释放时须确认目标仍是迁移时的目录，旧联接仍指向它，备份仍符合迁移校验记录；任一检查失败都会保留备份。中断后重新确认同一项可继续；迁移前已有的无校验记录目录只能人工核对。CLI 先运行 `codiscuss admin account migration-backups <账号>`，再运行 `codiscuss admin account release-backup <账号> <迁移编号> <目录类别> --confirm`。

### macOS 和 Linux 能不能用？

- **macOS 和 Linux 有面板后台和非隔离账号的代码路径。** `codiscuss panel open` 的窗口启动器依赖 Windows PowerShell、Edge 或 `rundll32`。在其他系统上可先运行 `codiscuss panel start` 启动后台，再用 `codiscuss admin account add <名> --no-isolate`。实例使用运行服务的系统用户身份，账号之间没有操作系统级文件隔离。macOS 和 Linux 上托管账号从创建到外网登录的整套流程仍待实机验证。独立 Windows 用户、入口保护、托盘图标和登录 Windows 时自启属于 Windows 功能。

## 经 SSH 用命令行管理（`codiscuss admin`）

下表各子命令都以 `codiscuss admin` 开头，结果以 JSON 返回，适合经 SSH 远程管理电脑。只有本机管理员可用。

| 场景 | 常用命令 |
| --- | --- |
| 启动、退出、重启、更新（**无需面板已运行**） | `codiscuss admin start` / `stop` / `restart` / `update [check]` |
| 查看状态、启停服务、开机自启 | `codiscuss admin status [--full]`、`service start\|stop\|restart`、`autostart on\|off` |
| 查看存储占用与清理临时文件 | `codiscuss admin storage`、`storage clean`、`storage repair`（预览）、`storage repair logs --confirm` |
| 让平台主理人分析占用 | `codiscuss admin storage analyze` |
| 按房间查看与清理附件 | `codiscuss admin storage attachments`（各房间占用）、`storage attachments ROOM`（列出附件）、`storage attachments ROOM clear ID... --confirm` |
| 绑定/解绑自建中转、生成接入码 | `codiscuss admin site status`、`site connect <接入码\|站点>`、`site disconnect`、`entry code` |
| 托管入口与隧道 | `codiscuss admin entry start\|stop`、`entry join <接入码>`、`entry open\|close relay\|tunnel`、`entry tunnel <域名>`、`entry tunnel reconnect` |
| 托管账号生命周期 | `codiscuss admin account list`、`account add <名>`、`account start\|stop\|disable\|enable\|remove\|password <名>`、`account isolate\|protect <名>` |
| 登录、密钥、技能与提示词 | `codiscuss admin login status <对象>`、`key add <对象> --base-url … --key …`、`skill install <对象> <技能>`、`workflow install <对象>`、`workflow update <对象>`、`prompt set <对象> --file …` |

注：`<对象>` 填 `owner` 代表管理员自己，填托管账号名代表对应托管账号。`account add` 中途失败时，解决问题后重跑同一命令会自动从缺少的步骤续做。

## 要注意什么

- **`admin stop` 不停托管实例**：`codiscuss admin stop` 会彻底退出面板、托盘图标、登录入口、隧道和管理员共议服务，但已启动的托管账号实例照常运行；要停某个托管实例用 `codiscuss admin account stop <名>`。
- **管理员权限提示**：经命令行创建或删除隔离 Windows 用户时，在管理员终端或管理员 SSH 会话里直接执行；非管理员终端会在电脑桌面上弹出 UAC 确认框。
- **面板专有项**：已有托管账号 AI 环境的“重新初始化”与切换管理面板界面语言目前仅在面板界面操作。
- **外网托管流量的边界**：托管账号经自建中转或 Cloudflare 隧道访问时，登录与会话保护都在你电脑上，但往来流量会经过 Cloudflare（计入 Workers 免费额度）。
