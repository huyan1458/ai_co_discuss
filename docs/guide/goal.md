# Goal

让主持人围绕一个目标持续推进工作：房间空闲时本机服务自动唤醒它接着做，直到完成、卡住、到达预算或你主动结束。

## 怎么操作

### 1. 开启 Goal

有三种开启方式：

- **右栏开启**：在房间右栏点“开启 Goal”，填写目标后确认。
- **建房时开启**：新建房间 → “协作方式（可选）” → “创建后”选“开启 Goal”，填写目标，点“创建并开启 Goal”。
- **命令开启**：在输入框发送 `/goal 目标内容`，主持人按原文开启；只发 `/goal` 时，主持人会从最近的对话提炼目标，提炼不出就不开启并说明缺什么。在输入框开头输入 `/` 时，菜单顶部的“模式”组会列出 Goal 命令。

### 2. 设置预算与空闲等待时长

开启或编辑 Goal 时只需填目标，预算默认不限。需要控制消耗时，在 Goal 弹窗或“编辑”中展开“高级设置”：

- **续跑上限**：限制自动续跑次数（默认不限）。
- **时长上限**：从开启后开始计时，暂停期间不计时。默认不限。
- **空闲多久后唤醒**：房间空闲多久后唤醒主持人一次，默认 2 分钟，可设为 30 秒到 30 分钟。

### 3. 看懂主持人什么时候续跑、什么时候停下等你

- **自动续跑**：主持人派出的工作全部结束、没有排队消息且你没有刚发言，房间空闲满设定时长后，本机服务自动唤醒主持人一次，消息流里显示“Goal 续跑 #N”。
- **暂不唤醒主持人的情况**：
  - 主持人上一次续跑只回复了你或向你提问、没有派活也没有重试失败成员时，不再自动唤醒，直到你回复。
  - 房间里只剩成员的答题卡在等你作答时，主持人不会被空闲唤醒。
  - 开启智能调度时，决策模型判断最近回答已在等你回复，会暂不唤醒主持人。
- **等待后台与待你确认**：主持人可声明当前处于“等待”（等后台任务）或“待确认”（等你拍板或补材料），右栏的 Goal 状态会标出。此时房间空闲也不唤醒它；到各自的等待期限（默认分别为 30 分钟和 60 分钟）后各会兜底唤醒一次检查或评估。只要你发一条消息，Goal 会立刻回到推进中。

### 4. 暂停、恢复、编辑与结束

- **暂停与恢复**：右栏 Goal 区域点“暂停”或“继续”，或在输入框发送 `/goal pause`、`/goal resume`。点击右栏“全部停止”也会暂停 Goal。
- **修改目标或预算**：右栏点“编辑”，或在输入框发送 `/goal edit 新目标`。
- **结束与再次开启**：主持人对照实际结果核验后会宣告完成，同一阻碍连续 3 次解决不了会宣告卡住，到达预算上限后主持人收尾一次并结束。你也可以随时在右栏点“结束”或发送 `/goal clear`。在最近一次 Goal 的结束卡上点“继续 Goal”，可以沿用原目标重新开启。进行中或已暂停的讨论会占用这个入口。

### 5. 绑定微信通知（简要）

如果你不想一直盯着电脑，可以在本机网页“设置 → 通知”的“微信”一栏点“扫码绑定”，用个人微信扫码绑定。当 Goal 处于“待确认”超过 3 分钟仍未收到你的回复时，本机服务会发微信提醒你（电脑绑定了线上站点时附带房间链接）；你在微信里直接回复就会发回该房间。详细的绑定步骤、测试与问题回复规则见[语音与通知](voice.md#微信通知)。

## 要注意什么

- **主持人与模式限制**：开启 Goal 需要一位由本机服务自动唤醒的主持人；Goal 与讨论不能同时进行。
- **不扩大权限**：开启 Goal 不会放大主持人的权限，它仍受成员项目权限和连续派活轮数上限约束，邀请成员需要另行授予房间管理权限。提交、推送或部署项目仍需你明确要求。
- **执行失败会自动暂停**：续跑时主持人执行失败（例如用量超限），Goal 会自动暂停并留一条标明原因的提示；处理完问题后在右栏点“继续”恢复。
- **不改变普通房间行为**：没有开启 Goal 的房间，成员做完手头任务就会停下等你，不会自动续跑。
