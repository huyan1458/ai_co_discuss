# 语音与通知

在网页里听 AI 朗读消息和项目文件、用麦克风语音输入，并绑定微信通知在 Goal 待确认或成员提问时收到手机提醒并直接回复。

## 朗读与语音输入：本机与云端的区别

你可以在网页“设置 → 语音”里分别选择**朗读**和**语音输入**的服务，每个服务的密钥与音色分开保存，切换回来仍在。

| 方式 | 可选服务 | 需要什么条件与费用 |
| --- | --- | --- |
| **本机朗读** | “本机”（Qwen3-TTS，可选加装 VoxCPM2 的 4 个平稳音色） | **不计费、无需密钥**。占约 3.5 GB 磁盘、使用显卡运行时需要至少 4 GB 显存（加装 VoxCPM2 再占约 4.5 GB 磁盘、需 8 GB 显存）。支持 Windows（NVIDIA 显卡 / AMD 或 Intel 独显 Vulkan）、macOS Apple Silicon（Metal）、Linux x64（Vulkan 或 CPU；纯 CPU 每段可能十几秒）。不支持调语速；朗读时自动启动，5 分钟闲置自动退出释放显存。 |
| **云端朗读** | 火山引擎（豆包语音合成 2.0）、阿里云百炼（CosyVoice）、Azure（神经语音，另填区域）、OpenAI（`gpt-4o-mini-tts`，2027-01-06 停用） | 填写对应服务商的 API Key（OpenAI 已保存过时直接沿用），按你的账号计费，不吃本机显存。支持调语速；火山引擎、OpenAI 与本机 Qwen3-TTS 支持设置语气提示。 |
| **本机语音输入** | “本机”（CrispASR + Qwen3-ASR） | **不计费、无需密钥**。占约 1.7 GB 磁盘、运行时约 2.5 GB 显存（与本机朗读同时跑时 8 GB 显存余量较紧）。支持 Windows / macOS Apple Silicon / Linux x64（无独显可用 CPU，识别耗时约等于录音时长）。用时自动启动，5 分钟闲置自动退出。 |
| **云端语音输入** | 火山引擎（录音文件识别 2.0）、OpenAI（`gpt-transcribe`，2027-02-26 停用） | 填写对应服务商的 API Key，按你的账号计费。 |

### 安装本机朗读与本机语音输入

`local-tts-setup`（本机朗读）和 `local-stt-setup`（本机语音输入）这两个技能都会**随 `codiscuss setup` 一起自动安装**到你勾选的本地 AI 软件里，不需要手动下载技能。

**对谁说、在哪说**：打开你电脑上任意已安装共议技能的本地 AI 对话（在外部终端的 Claude Code / Codex / `agy` 窗口，或在共议房间里 `@` 一位能联网下载、执行命令并写入本机服务目录的本地成员均可），直接告诉它：

- 安装本机朗读：“请按 `local-tts-setup` 技能帮我安装并配置本机朗读语音。”（若想加装 4 个适合听小说的 VoxCPM2 音色，顺便说明“一并安装 VoxCPM2 模型”。）
- 安装本机语音输入：“请按 `local-stt-setup` 技能帮我安装并配置本机语音输入。”

AI 会自动检查你的显卡、磁盘与共议版本，告知预计占用后下载引擎与模型、写入本机令牌并验证可用。安装完成后，刷新网页到“设置 → 语音”就能看到并选中“本机”。若刚升级且网页没有新选项，可运行 `codiscuss service restart` 重启负责唤醒 AI、处理本机任务的后台讨论服务，再刷新网页。本机网站是提供房间页面的另一进程。

### 使用朗读与语音输入

1. **配置音色**：在“设置 → 语音”设置通用音色，也可按 AI 平台（Claude、Codex、Gemini 等）和项目文件分别指定音色并试听。
2. **朗读消息与开启播报**：
   - 单条朗读：点消息工具栏的“朗读”（手机在“…”菜单）；选中一段文字后点“听当前”可从选中处开始。读完自动顺读后续消息，代码块自动跳过。正在读的句子会高亮，点一下暂停、再点继续；底部可点“跟随”随朗读滚动，或点“退出”停止。
   - 自动语音播报：点输入框右下角的扬声器按钮（“开启语音播报”），新回复到达时自动朗读摘要（短答读全文，长答读第一段），执行失败、待授权和讨论结束也会播报一句。锁屏或切到其他 App 时继续播放，支持耳机按键控播；本机缓存命中时，重听无需再次调用语音服务。
3. **朗读项目文件**：在“文件”页打开 Markdown 文件，预览模式标题栏点“朗读”（不读开头 `---` 元数据）；收起为悬浮窗时继续播，切到源码、换文件或关闭预览时停止。
4. **语音输入**：点（或按住）输入框右下角的麦克风按钮说话，再点一次（或松开）转成文字插入草稿，单次最长 5 分钟（浏览器首次使用会请求麦克风权限）。
5. **强行结束残留本机进程**：如果程序异常退出导致本机语音进程占着显存，在“设置 → 语音”的“本机进程”一行查看进程与 PID，点右侧电源按钮强行结束。

## 微信通知

微信通知通过腾讯 iLink 机器人通道与你的**个人微信**绑定，由电脑上的本机服务通过腾讯 iLink 收发纯文本。微信登录凭据只保存在这台电脑上。

### 怎么操作

1. 打开本机网页的“设置 → 微信通知”，点击“扫码绑定”。
2. 用你的**个人微信**扫描页面上的二维码并确认登录。
3. **发一条验证消息**：扫码完成后，先在手机微信里给刚刚绑定的机器人发任意一条消息（让机器人建立对话上下文）。
4. 回到网页点“发送测试”，右下角提示“测试通知已发出”且微信收到测试消息，即绑定成功。之后不需要时可点“解除绑定”。

### 什么时候会收到微信通知，回复后会发生什么

- **Goal 待确认超过 5 分钟**：主持人声明 Goal 处于“待确认”且 5 分钟内你未在网页回复时，发微信提醒你（电脑绑定了线上站点时附带房间链接，在已配对手机上可直接打开）。直接回复会发往最近通知对应的房间；有多个房间在等你时，引用目标房间的通知再回复。
- **成员向你提问超过 5 分钟**（无论是否开启 Goal）：只要房间里出现等你拍板的答题卡且 5 分钟未作答，就会发微信列出题目和带编号的选项（推荐项标“（推荐）”）。
  - 回复编号（多选用空格或逗号分隔，多道题按顺序写编号如 `1 2`）或与选项完全相同的文字，直接按该选项提交答案并交回提问成员，不经过主持人。
  - 回复其他文字，交给主持人理解后代为选择或在房间里追问。
  - 若问题已答过、已取消或已更新为新版本，微信会说明原因且不会误提交。

## 要注意什么

- **依赖本机服务在线**：朗读、语音输入和微信通知都由本机服务执行；电脑关机或本机服务未运行时，手机等已配对设备也无法使用这些功能。
- **登录过期重绑**：微信登录长期未使用或失效时（提示登录已过期），回到“设置 → 微信通知”重新“扫码绑定”即可。
- **本机语音识别提示**：本机 Qwen3-ASR 对中英混说、标点和大小写识别较好，但逐字母念的缩写（如 N-P-M）或代码标识符容易识别偏差，发送前可顺手改一下草稿。
