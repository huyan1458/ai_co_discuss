# 第一次使用

用共议（AI CoDiscuss）建一个房间，给成员发一句话；看到它在房间里的回答，就算跑通了。

## 使用前须知

- **费用。** 共议免费开源。本地 AI 沿用你的账号、订阅或用量额度。模型 API、智能调度、生图、联网搜索和云端语音按所选服务计费。本机语音无需云端语音额度。
- **系统。** 准备 Node.js 24+ 和 Python 3.10+。在 Windows、macOS 或 Linux 上，用下方的 `local` 命令启动本机网站；没有图形桌面时不会自动打开浏览器。管理面板的桌面窗口、托盘图标、“共议”快捷方式、登录时自启与托管账号的入口保护按 Windows 使用。
- **数据。** 默认安装时，房间记录在 `~/.codiscuss/local/discuss.sqlite3`，配置、成员凭据和已保存的 API 密钥留在本机服务目录 `~/.codiscuss`。不选项目目录时，房间会在 `~/.codiscuss-workspace` 下取得自己的草稿文件夹。卸载 npm 包会保留数据。
- **关机或休眠。** 电脑离线时，配对设备无法经它访问房间，本机服务也无法投递新任务。电脑和服务恢复后，仍在授权期内的设备会重新连接。先看房间里的回答或失败卡，再决定是否重试。
- **只有网页版 AI。** 网页版 ChatGPT、Claude 和 Gemini 无法作为成员接入。可以用已登录的本地 AI 软件，或准备模型服务商的 API Key。能运行共议命令的其他本地 AI 可走[手动接入](members.md#手动接入)。

## 怎么操作

### 1. 确认至少一种 AI 能用

选择你已经安装的一种软件，在共议之外先确认账号可用。

- **Claude Code CLI**：在终端运行 `claude auth status`，查看登录状态。如果在共议管理面板选择 Setup Token，可在已登录 Claude 的电脑上运行 `claude setup-token`，将生成的令牌填入面板。
- **Codex CLI 或 Codex App**：CLI 需要 0.163.0 或更新版本，可用 `codex login status` 查看登录状态。使用 App 时，打开已登录的窗口并保持运行。
- **Gemini（Antigravity CLI 或 Antigravity App，CLI 命令为 `agy`）**：打开你要接入的软件，按提示登录，发一句话并确认能收到回答。

如果用模型 API，只需先准备 Key。共议安装器会安装Pi（在本机调用模型 API、执行成员任务的程序），之后在建房时选择模型。

### 2. 安装共议，打开本机站点

在终端依次运行：

```sh
npm install --global ai_co_discuss@latest
codiscuss setup
```

按提示确认检测到的软件并安装技能。在 Windows 的交互安装中，还可以选择创建“共议”快捷方式。默认配置完成后，浏览器打开 `http://127.0.0.1:8765`。如果只看到终端输出，手动打开它列出的本机地址；如果提示“待处理”，根据对应项目的提示修正后再运行 `codiscuss setup`。

以后打开房间用 `codiscuss local open`，查看状态用 `codiscuss local status`，停止本机站点及其管理的服务用 `codiscuss local stop`。

### 3. 在网页建房，收到第一条回答

1. 左栏 → “新建房间”。在“这次做什么”填写“话题名称”，例如“第一次测试”。“项目目录（可选）”可以留空。
2. “谁来参与” → “添加 AI” → 选一个已配置的平台。下方会出现它的成员卡。第一次测试可只加一位。
3. 如果用 API，例如“OpenAI”，点成员卡正面的“设置”区域翻面。在“地址”“协议”“密钥”“模型”中核对预填值，填写 Key 并选模型，再点“完成”回到卡片正面。
4. 确认希望主持的成员带有皇冠；需要更换时点目标卡片的皇冠“设为主持人”。在“协作方式（可选）”的“创建后”选“不开启”，先用普通房间。
5. 点“创建并连接”。进入房间后，右栏显示成员。若全是手动启动的成员，建房按钮为“创建协作房间”，先按[手动接入](members.md#手动接入)完成注册。
6. 在底部输入框输入 `@`，选中成员，写“请回复一句，告诉我你收到消息了”，点“发送”。消息卡会显示处理状态，随后对话区出现该成员的回答。

### 4. 也可以从已有的 Claude Code 或 Codex 对话建房

下面的例子需要本机站点已启动，并且 Claude Code 与 Codex 都已配置。打开你准备让它主持的**项目对话**，把这段话发给它：

> 请使用 discuss-host 和 discuss-participant 技能，在 http://127.0.0.1:8765 新建“缓存设计评审”房间并立即开启讨论。由你在当前会话主持，邀请另一种已配置的软件作成员：如果你是 Claude Code，就邀请 Codex；如果你是 Codex，就邀请 Claude Code。使用当前项目目录，只读评审，不改文件。讨论目标是找出一个缓存失效风险和一个验证办法，上限 3 轮、60 分钟。建好后告诉我房间名称和阅读链接。

在 Codex 中可以用 `$discuss-host` 和 `$discuss-participant` 点名技能。AI 会使用 `codiscuss launch start --file …`；你不用自己找会话编号或填写启动文件。打开本机站点，左栏应出现“缓存设计评审”，房间中能看到本场讨论。若只想建普通房间，把“立即开启讨论”改成“只建协作房间，不开启讨论”，并去掉讨论目标与上限。

## 要注意什么

- 开工前看成员卡上的项目权限。支持权限控制的程序启动 CLI 和 API 成员通常默认只读；手动接入沿用原窗口权限。不同软件提供的档位不同。
- 从终端只输入 `codiscuss` 会在前台运行服务。平时要打开网页，用 `codiscuss local open`。
- Gemini 的 Antigravity CLI 无法从当前 CLI 对话发起由自己主持的全自动讨论，可改从网页创建。
- 默认本机地址只在这台电脑上使用。外出访问时，先把电脑绑定到线上站点，再在电脑前配对手机或平板。
