# 名词与概念

认识共议（AI CoDiscuss）的六个概念，你就能判断该把任务发给谁、从哪里打开房间。

## 怎么操作

| 你会遇到的概念 | 怎么用 |
| --- | --- |
| 房间 | 你和 AI 共享消息、附件与结论的地方。打开房间就能发任务，也可以在里面开启讨论或 Goal。 |
| 成员 | 加入房间的 AI。输入 `@` 选中它，就能直接给它任务。界面上的“专家”就是成员，例如“邀请外部专家”。 |
| 主持人 | 你指定的成员，卡片上有皇冠。没有 `@` 任何人的消息交给它，由它回答或分派给其他成员；开启智能调度后，明显该由某位成员回答的消息会直接交给那位成员。 |
| 本机服务 | 在电脑上唤醒 AI 软件或调用模型 API 的程序。用 `codiscuss local status` 查看它是否在运行。 |
| 本机站点 | 在电脑上打开的房间网站，默认地址是 `http://127.0.0.1:8765`。房间、消息和附件保存在这台电脑上。 |
| 线上站点 | Cloudflare 上的远程入口。手机等设备先和电脑配对，再经加密中转访问电脑上的房间。 |

## 要注意什么

旧文档和界面可能用不同叫法。遇到下面这些词时，可以这样对照。

| 旧称或别称 | 本手册或当前界面 |
| --- | --- |
| 参与者、专家 | 成员 |
| 自由协作 | 房间内未开启讨论或 Goal 时的协作 |
| 接入程序、runner | 本机服务 |
| 成员栏、右侧面板 | 右栏 |
| 昵称 | “显示名称” |
| Antigravity、agy | 本地成员 Gemini（Antigravity CLI 或 Antigravity App，CLI 命令为 `agy`）；另有 Gemini 模型 API。 |
| 一次性绑定令牌 | 面板用“接入码”绑定电脑；接入码含站点信息和绑定令牌。设备扫码时用的是“配对码”。 |
| 信任设备 | 借出 AI 时的“本机权限”选项“不受限” |
