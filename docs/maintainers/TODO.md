本地回归使用临时数据，不接入真实专家。CI 覆盖 Windows / Ubuntu 和 Python 3.10 / 3.14；自动运行的软件适配器、浏览器送达和原生任务仍需相应实机证据。真实讨论验证沿用用户授予的房间、参与者和运行边界。
