# 维护计划

## 当前目标与已确认边界

把现有讨论实现整理为可分享、自包含的开源项目：README 面向首次使用者，所需 Skill、网站源码与素材、配置教程、测试和部署说明随仓库提供。许可证已确定为 MIT。

保留各 AI 在自己软件中形成观点的边界；本地 CLI 可读写，在线专家在原聊天回答并由主持人/用户代发。使用软件原生定时功能，不恢复独立讨论监控或模型 API 编排。发言权、串行安排、原文署名、提交去重和非必要不生成回执的规则继续有效。

## 本次整理

1. 将 README 从历史任务记录改为项目入口，详情放 docs；历史中的有效决策归入工作流和架构，尚未实机验证的事项保留在 TODO。
2. `.agents/skills/` 仅分发主持与参与两份讨论 Skill，移除个人路径与公共站点默认值，提供跨软件加载指引；个人通知 Skill 不纳入项目。
3. 测试集中到 `tests/`，Pages 构建脚本到 `scripts/`；根运行入口不变，现有业务代码不重写。
4. 公开配置使用占位资源 ID，本机真实配置独立保存且忽略；补齐 MIT、第三方声明、贡献和安全说明。
5. 验证迁移路径、现有测试、完整构建和新目录下的本地运行。只在本地检查，不替使用者创建云资源或部署。

## 后续维护

以 TODO 记录仍需真实环境验证的能力，不把已有历史测试替代当前外部行为。下一次获准真实讨论时验证原生任务、在线专家往返和收尾；微信界面及新建聊天按实际使用结果补证据。身份认证、模型 API 编排和并行专家队列均不在本次整理范围。
