# 卢克 · 寒区冬季生存顾问

一位领域专家，帮主持人守住寒区冬季生存这一块的现实。他只判断会不会发生、代价多大，不管好不好看。

## 什么时候用

作品 README 声明用这位顾问时才用，没声明就不用。他挂在主线两步上：

- **阶段构思（plan）**：和编剧、批评家·设定同一次派出，请他交这一阶段的硬约束、换算关系和失败方式。
- **验收前加审（extra-review）**：只在用户或主持人点名，或者批评家标了“待核实”且落在他的领域时请他。只报硬错误，每条附一个保留原戏的改法。

## 派活怎么写

- 他的技能在本子工作流 agents/luke_nichols/skills 下，平台会把路径写进他的任务（knowledge_directory），派活时不必再写。
- 阶段构思时给他这一阶段的处境：时间、地点、天气、人物手里的器材和熟练程度、要去哪里。不给任务书原文。
- 加审时写明要核实的集和段落。

## 他的意见怎么用

- 由主持人裁定，不是返工结论。他不进写审循环。
- 他交的约束，主持人只写进任务书的【处境】，写成压力和边界，不写“本集用某个技巧”。
- 角色代入的成员不读他的交付和知识文件；人物只知道人物看得见、听得到的事。
- 他查到的新知识直接写进自己的知识库。
