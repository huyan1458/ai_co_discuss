# 〔作品名〕

〔一句话简介：谁，在什么世界里，想要什么。〕

续写或重写之前先读本文件。

**文件分工**（各管各的，不混用）：

| 文件 | 放什么 | 谁维护 | 什么时候改 |
| --- | --- | --- | --- |
| README.md（本文件） | 作品总纲：故事事实、用户决定、分阶段大纲、候选方案、留白与待决 | 主持人 | 每集验收后补事实；大纲改动要用户同意 |
| [世界.md](世界.md) | 世界规则、画面库、地图 | 主持人 | 设定采用后；候选条目写进正文时改标【正文】 |
| [文风.md](文风.md) | 作家的腔调、禁用词、样本、用户标注 | 写手起草，用户审定 | 用户标注时 |
| [工作台.md](工作台.md) | 没做完的事：写到哪了、正在做什么、伏笔总表、待办清单 | 主持人 | 每集验收、每轮修改收尾后清理 |
| [排线表.md](排线表.md) | 全书排布：每集主事、排线表、断线检查 | 主持人 | 写前和改旧集前先查表填格，验收后按定稿改，阶段末更新断线检查 |
| `状态/` | 只给作者看的账本：主角、物资、据点、人物、线索、分集记录 | 记录员 | 每集定稿后 |
| `人物/`（可选） | 重要人物一人一档，只写这个人自己知道的事；他不知道的事放 `作者层.md` | 主持人建档，记录员每集追加 | 用角色代入时才需要 |
| `正文/` | 各集正文、档案和交稿附注 | 写手 | 写集和修订 |

不放错地方：接下来几集的安排放排线表，没做完的事放工作台，账目不写进正文。

**约束分级**：各节对续写的约束力从上往下依次减弱。

| 级别 | 章节 | 含义 |
| --- | --- | --- |
| 必须遵守 | 一、故事事实；二、用户决定 | 不能冲突，不能违反 |
| 方向 | 三、分阶段大纲 | 用户同意的大框架，要改先和用户商量 |
| 候选 | 四、候选方案 | 可用、可改、可弃 |
| 留白 | 五、留白与待决 | 没有定，续写时自由处理；标“待用户决定”的，动笔前先问用户 |
