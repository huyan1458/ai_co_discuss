# 浏览器实测

目的：把浏览器操作与端到端页面验证交给最擅长操作浏览器的执行者，用真实截图和运行态证据验收，不靠肉眼猜代码效果。

## 流程

1. **请进角色**：启用本子工作流时请进**浏览器实测**。
2. **下发验收清单**：主持人写明启动方式（或目标 URL）、要覆盖的关键路径、视口要求（默认 1440×900、100% 缩放，有移动端需求时补充）、以及需要截图留证的页面状态。
3. **实测取证**：**浏览器实测**按清单操作真实浏览器，记录控制台错误、网络异常与交互表现，将关键页面截图作为附件交回，并清理自己起的临时进程。
4. **主持人收口**：核对截图与异常清单；通过则请离**浏览器实测**并进入交付，不通过则定位修复后再复测。

## 约束

- 遇到登录密码、两步验证、验证码或付款等须本人确认的操作时立即停下交由用户完成，不尝试绕过。
- 实测脚本或临时服务不污染仓库代码。
